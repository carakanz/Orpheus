## Решения

- **Исключение из правила уголка [док].** У бесшовных текстур земли и воды пурпурного уголка нет: он был бы виден решёткой через каждые 4 тайла на всём экране. Они помечены папкой `_TEMP`, именем `TEMP_` и строкой манифеста с пометкой «без уголка» в `notes`. `tools/check_temp_assets.py` не требует уголок у строк с этой пометкой (правка проверки в три строки — иначе она красная; это не ослабление «чтобы позеленело», а исключение, заданное постановкой шага). Записано в `work/modules/art.md`.
- **Мак — напрямую через ComfyUI**, а не через сервер ассетов: тот же граф (Z-Image base `z_image_bf16`, 30 шагов, cfg 4, `res_multistep`/`simple`, shift 3), но свой размер кадра (объекты 768 px — быстрее) и свой негативный промпт. Задания ставятся в конец очереди; модели не трогаются. Скрипт — `tools/art_stage1.py`, набор — `art/style/sets/e19.json`.
- **Перечень цветов убран из стилевой части промпта** (вывод `STYLE.md`, п. 11): цвета названы в описании предмета.
- **Бесшовность — швом наименьшей разницы**, а не сдвигом на половину со смешиванием (`art_process.make_seamless`): у того на серединах краёв остаётся кусок шва сдвинутой копии, на крупной графике он виден. Здесь: края перекрываются полосой 96 px, граница идёт по пути наименьшего отличия (как в image quilting), растушёвка 1,5 px; по вертикали путь замкнут.
- **Обрыв собирается скриптом**: маска площадки (кромка в 1 тайле от края ячейки, волна кромки с целыми частотами — на границах ячеек ноль, сегменты стыкуются) → под южной кромкой полоса «лицо» высотой 192 px (1,5 тайла), нижняя треть темнее → контур, светлая кромка, тень. Земля в сегменте прозрачная: сегмент кладётся поверх любой земли. Боковые (запад, восток) и задняя (север) кромки — только контур: при виде сверху с наклоном их стенка не видна. Торцы — стенка сходит на нет по ширине ячейки.
- **`.meta` не создавал**: импорт настроит шаг 1.4 (нужно: `spritePixelsToUnits 128`; объекты — pivot внизу по центру `(0.5, 0)`; земля и вода — wrap repeat; сегменты обрыва — pivot по сетке ячейки). Существующие `.meta` заглушек A-002 содержат нарезку спрайтов из редактора — руками такое не подделываю.
- Сырые картинки Мака (1024 px, ~1,5 МБ каждая) в git не кладу: воспроизводятся по зерну и промпту из набора; лежат в папке `--raw` (по умолчанию `build/art_e19/raw`, вне git).
- Слово Автора 13.11 (через координатора): весь набор ставится в очередь сразу, без этапа проб и без предела «4 задания»; пока Мак рисует — скриптовые заглушки тем же набором имён, картинка с Мака заменяет скриптовую под тем же именем.

## Как воспроизвести

```
python tools/art_stage1.py queue <ключ> … --raw <папка>     # заказ
python tools/art_stage1.py collect --raw <папка>            # приём готового (wait — ждать всё)
python tools/art_stage1_build.py --raw <папка>              # обработка, манифест, лист work/screens/E1-9_sheet.png
python tools/check_temp_assets.py
```

Нет сырой картинки ключа — `art_stage1_build.py` рисует ассет скриптом (простые формы в палитре стиля), в манифесте пометка «скрипт».

## Промпты

Промпт = стиль + предмет + камера (по виду), плюс негатив. Полный текст — `art/style/sets/e19.json`.

- **Стиль:** `clean hand-drawn 2D game illustration, bold confident dark plum-brown outlines of even weight around every shape, flat color fills with simple two-step cel shading and one crisp highlight, strong readable silhouette, large graphic simplified shapes, very little small detail, bright saturated sunny Mediterranean colors, smooth vector-like finish`
- **Камера «земля»:** вид строго сверху, земля уходит за все четыре края, без объектов и теней, ровный свет.
- **Камера «объект»:** вид сверху с наклоном 45°, один предмет по центру, свет сверху слева, без падающей тени, светлый тёпло-серый фон.
- **Камера «обрыв»:** вид сверху с наклоном 45°, свет сверху слева.
