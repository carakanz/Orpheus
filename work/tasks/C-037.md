# C-037 — графика в Mono-сборке: объекты розовые, интерфейс пропал

## Зачем
Блокирует приёмку 2.8/3.7: в сборках с 18.11 (после E3-4, merge `f7f5b02`) в собранном
игроке объекты (деревья, растения, декор, кучи) рисуются маджента-заглушкой, у Автора
в живом окне пропал весь интерфейс. Сборка 17.11 (`80914c9`, до E3-4) — нормальная.

## Симптомы и улики
- `Player.log` игрока (сборка main `22ee453`, 19.11): `ERROR: Shader Orpheus/Objects
  shader is not supported on this GPU (none of subshaders/fallbacks are suitable)`;
  строка `[objects] шейдер: Orpheus/Objects` есть — Shader.Find прошёл, subshaders не подошли.
- Офлайн-снимок той же сборки: `build\shots\20261119-1103\04_meadow_forest.png` — сплошная маджента.
- Тот же лог у tc036-сборки (C-035, 19.11 03:11) — регрессия E3-4, не C-035/36.
- Земля (`Ground.shader`), тон суток, тени — рисуются. URP 17.6.0 в manifest, RP-ассет
  (`guid 681886c5...`) проставлен во всех уровнях QualitySettings.
- `Ground.shader` и `Objects.shader` — одинаковые теги SubShader (`RenderPipeline=UniversalPipeline`,
  LightMode Universal2D/UniversalForward), оба без `#pragma target`. Ground OK, Objects нет.
- E3-4 в Objects.shader добавил: `float4 _OrphActors[8]` (массив uniform'ов, индексирование),
  `CreatureFade`, varyings `baseY : TEXCOORD2`. См. `git diff ea4f43a f7f5b02 -- client/Assets/Shaders/Objects.shader`.
- Интерфейс: процедурный UI идёт через `Resources/UiShape.shader` (менялся 18.11, C-030).
  Проверить отдельно: если UiShape тоже «not supported» в Player.log — это тот же класс причины.

## Гипотезы (проверять по порядку)
1. Динамический индекс `_OrphActors[i]` требует SM 3.0+; без `#pragma target` дефолт ниже —
   в билде шейдер компилируется в нерабочий. Лечится `#pragma target 3.0` (или 3.5) в пассах
   Objects.shader (и сверить с пассами Ground.shader).
2. Протухший шейдерный кэш Library у сборочной копии — чистый перестрой (удалить `client\Library`,
   собрать заново; один процесс Unity на копию, Hub должен быть запущен).
3. Если у UiShape та же причина — починить аналогично.

## Что делаем
1. Воспроизвести: `tools\shots.ps1 -Only "04_meadow_forest"` в копии — смотреть PNG (маджента есть).
2. Найти причину (Unity batchmode -logFile, ошибки импорта шейдеров; эксперименты 1→3).
3. Починить минимальным изменением.
4. Проверить снимками и посмотреть каждый глазами: `04_meadow_forest`, `26_real_forest_64`,
   `31_real_mountains`, `--ui-demo bag`/`hotbar`-сцены (из shots.json) — мадженты нет, HUD виден.
5. `tools\build_client.ps1 -Backend Mono -Smoke -HostSmoke` — код 0.

## Готово, если
Снимки новой сборки без мадженты, HUD на ui-сценах виден; host-smoke 0; П принято.
