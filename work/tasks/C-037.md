# C-037 — графика в Mono-сборке: объекты розовые, интерфейс пропал

## Зачем
Блокирует приёмку 2.8/3.7: в сборках с 18.11 (после E3-4, merge `f7f5b02`) в собранном
игроке объекты (деревья, растения, декор, кучи) рисуются маджента-заглушкой, у Автора
в живом окне пропал весь интерфейс. Сборка 17.11 (`80914c9`, до E3-4) — нормальная.

## Симптомы и улики
- `Player.log` игрока (сборка main `22ee453`, 19.11): `ERROR: Shader Orpheus/Objects
  shader is not supported on this GPU (none of subshaders/fallbacks are suitable)`;
  строка `[objects] шейдер: Orpheus/Objects` есть — Shader.Find прошёл, subshaders не подошли.
- Офлайн-снимок той же сборки: `build\shots\20261119-1103\04_meadow_forest.png` — сплошная маджента.
- Тот же лог у tc036-сборки (C-035, 19.11 03:11) — регрессия E3-4, не C-035/36.
- Земля (`Ground.shader`), тон суток, тени — рисуются. URP 17.6.0 в manifest, RP-ассет
  (`guid 681886c5...`) проставлен во всех уровнях QualitySettings.
- `Ground.shader` и `Objects.shader` — одинаковые теги SubShader (`RenderPipeline=UniversalPipeline`,
  LightMode Universal2D/UniversalForward), оба без `#pragma target`. Ground OK, Objects нет.
- E3-4 в Objects.shader добавил: `float4 _OrphActors[8]` (массив uniform'ов, индексирование),
  `CreatureFade`, varyings `baseY : TEXCOORD2`. См. `git diff ea4f43a f7f5b02 -- client/Assets/Shaders/Objects.shader`.
- Интерфейс: процедурный UI идёт через `Resources/UiShape.shader` (менялся 18.11, C-030).
  Проверить отдельно: если UiShape тоже «not supported» в Player.log — это тот же класс причины.

## Гипотезы (проверять по порядку)
1. Динамический индекс `_OrphActors[i]` требует SM 3.0+; без `#pragma target` дефолт ниже —
   в билде шейдер компилируется в нерабочий. Лечится `#pragma target 3.0` (или 3.5) в пассах
   Objects.shader (и сверить с пассами Ground.shader).
2. Протухший шейдерный кэш Library у сборочной копии — чистый перестрой (удалить `client\Library`,
   собрать заново; один процесс Unity на копию, Hub должен быть запущен).
3. Если у UiShape та же причина — починить аналогично.

## Что делаем
1. Воспроизвести: `tools\shots.ps1 -Only "04_meadow_forest"` в копии — смотреть PNG (маджента есть).
2. Найти причину (Unity batchmode -logFile, ошибки импорта шейдеров; эксперименты 1→3).
3. Починить минимальным изменением.
4. Проверить снимками и посмотреть каждый глазами: `04_meadow_forest`, `26_real_forest_64`,
   `31_real_mountains`, `--ui-demo bag`/`hotbar`-сцены (из shots.json) — мадженты нет, HUD виден.
5. `tools\build_client.ps1 -Backend Mono -Smoke -HostSmoke` — код 0.

## Готово, если
Снимки новой сборки без мадженты, HUD на ui-сценах виден; host-smoke 0; П принято.

## Состояние
Открыта 19.11 (снимок Автора + офлайн- shot). Ветка task/C-037, копия .claude/worktrees/tc037.

## Место остановки
19.11, исполнитель. Причина НАЙдена и починена (гипотеза №1 НЕ подтвердилась):
- Воспроизведение в tc037: сборка сломанного кода → лог `build\logs\c037_repro_build.txt`:
  `Shader error in 'Orpheus/Objects': syntax error: unexpected token 'f' at Assets/Shaders/Objects.shader(87) (on dx11)`;
  снимок `build\shots\20261119-1202\04_meadow_forest.png` — маджента деревьев (земля нормальная).
- Причина: E3-4 в Objects.shader(86) literals `2f : 1f : 0f` (C++-суффикс f) — компилятор
  dx11 (Unity 6, dxc) их отклоняет → шейдер не компилируется при упаковке сборки →
  в игроке «not supported on this GPU» → маджента. Динамический индекс `_OrphActors[k]`
  ни при чём (константный цикл разворачивается); `#pragma target` не добавлял (Ground без него работает).
- Правка 52d7f9d: `2.0 : 1.0 : 0.0` (одна строка). Пуш origin task/C-037.
- UiShape.shader проверен: `#pragma target 3.0` есть, в Player.log «not supported» нет — HUD
  чинить отдельным механизмом не требуется (по дополнению оркестратора: проверить после починки Objects).
- Дальше: пересборка (идёт, `build\logs\c037_fix_build.txt`) → снимки глазами: 04_meadow_forest,
  26_real_forest_64, 31_real_mountains, C-008_bag, C-008_hotbar (HUD) → финальный
  `build_client.ps1 -Backend Mono -Smoke -HostSmoke` (код 0) → «Состояние», пуш.
- 19.11 финал: всё выше сделано — снимки чистые (смотрены глазами), smoke 0, host-smoke 0, build errors=0.
  Карточка закрыта исполнителем, ждёт П. Коммит починки: 52d7f9d.

## Решения
- [гип] Гипотеза №1 (динамический индекс `_OrphActors[i]` требует `#pragma target 3.0`) — НЕ подтвердилась:
  лог сборки даёт точную причину `syntax error: unexpected token 'f' at Objects.shader(87) (on dx11)` —
  синтаксис строки литералов, до семантики индексирования дело не доходит. `#pragma target` НЕ добавляли
  (минимальная правка; Ground.shader без target работает, цикл с константной границей разворачивается).
- [гип] Гипотеза №2 (протухший кэш Library) — отпала: чистый лог сборки воспроизводит ошибку компиляции шейдера.
- «Пропал HUD» — не отказ шейдера UI (у UiShape есть target 3.0, в Player.log «not supported» нет):
  magenta-заглушка Objects ломала картинку поверх/раньше UI. После починки на C-008_bag/C-008_hotbar
  HUD полный (сумка, крафт, хотбар, сферы UiShape 72/100, мини-карта) — проверено глазами на Mono-сборке tc037.
- Строки `Hidden/Universal Render Pipeline/Bloom|… stripped from the build` в Player.log — штатный
  стрипнинг URP post-processing (нет в build list), не наш дефект (слово оркестратора 19.11).
