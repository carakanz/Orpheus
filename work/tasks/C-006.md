# C-006 — агрессивные враги появляются только ночью, с рассветом уходят

**Поток:** Я (ядро/бой). **Ветка:** `task/C-006` (копия `.claude/worktrees/tc006`, от main `9a0f9d2`). **Откуда:** слово Автора 15.11 после игры: «Можешь сделать так, чтобы мобы агрессивные только ночью появлялись. Сейчас невозможно нарубить». **Разблокирует:** добычу днём (шаги этапа 2–3 с рубкой/копанием без постоянных драк).

## Задачи

1. Попытки появления — только в фазе «ночь»; днём, в сумерки и на рассвете — ни одного нового врага.
2. С рассветом враги уходят: без цели — сразу/за 1–2 с, детерминированно; в бою — доигрывает и уходит по потере цели или через N с дня; не посреди удара, обычным `RemoveEntity`.
3. Ночной множитель (`NightMultX1024`), запрет света и пола — не трогать.
4. Backlog [док]: `docs/02` 8.5 с дневным появлением расходится со словом Автора.
5. Тесты: день 10 мин — ноль; ночь — как раньше; рассвет без цели — уходит; рассвет в бою — доигрывает и уходит; детерминизм; старые тесты, ждавшие дневного появления, — сценарий на ночь без ослабления.

## Сделано

Код — только `src/Orpheus.Core/Sim/Spawner.cs` (протокол, сохранение, мозг врага не менялись).

- **Появление (`StepSpawnAttempt`)**: первым делом `PhaseOf(WorldTime) != Night → return`; попытка раз в `SpawnAttemptNightTicks` = 120 тактов (4 с), лимит `SpawnNightLimit` = 8 (группа — прежней формулой). Константы `SpawnDayLimit`/`SpawnAttemptDayTicks` и линейный ритм сумерек удалены (внешних ссылок не было). Ночью `_spawnNextTry` не продвигается днём — в первый такт ночи попытка идёт сразу.
- **Уход с рассветом (`StepDespawn`)**: в фазах «рассвет» и «день» (`IsDaylight`), после проверки активной зоны, до правила «дальше 80 т»:
  - замах идёт (`AttackWindup > 0`) — никогда не уходит, удар доигрывается;
  - без цели — уходит на такте, где `(tick + id) % 30 == 0` (`DaylightDespawnStaggerTicks`): каждый в пределах 1 с, не все в один кадр, без состояния;
  - с целью — уходит, когда с начала рассвета по часам мира прошло ≥ 900 тактов часов (`DaylightFightTicks`, 30 с; `TicksSinceDawn(WorldTime)`); потерял цель раньше — уходит по правилу «без цели».
  - Удаление — тот же `RemoveEntity`, что у 8.8 (от хвоста, вне фаз; рассылается обычным remove — «полупризраков» нет).
- Ночное усиление (`NightMultX1024`, `NightSightMultX1024`), запрет света ≥ 0,5 и построенного пола — без изменений.

## Решения

1. **Сумерки — без появлений** (допущение): Автор сказал «только ночью»; сумерки (1 мин) считаем не ночью. Если Автор захочет — одна строка в `StepSpawnAttempt` (`!= Night` → `Day || Dawn`).
2. **Уход — с начала рассвета, не с начала дня**: на рассвете уже светлеет, «мобы только ночью» — рассвет не ночь; к полному дню поле пустое.
3. **Без цели — разброс ≤ 1 с по номеру** (`(tick + id) % 30`), а не все в один такт: детерминированно, без нового поля мозга (формат сохранения не трогаем).
4. **Бой — 30 с светлого времени по часам мира от начала рассвета**, а не по счётчику на враге: без состояния (сейв формата 6 не меняется), одинаково после загрузки. При ускоренных часах (`DayScale`) 30 с часов короче в тактах симуляции — это «секунды дня», а не реального времени.
5. **Посреди замаха не уходит**: условие `AttackWindup == 0`; на такте ухода удар либо не начат, либо приземлился в этом же такте (тест проверяет: замах перед тактом ухода ≤ 1).
6. **`--debug-enemies` днём при включённом спавнере** — тоже уходят (их не отличить от спавненных). Для отладки днём — `--no-spawn` (host-smoke и так идёт с `--no-spawn`). Если Автору мешает — флаг «расставлен» в мозг (это формат сейва → отдельная карточка).
7. **Правки тестов** (проверки не ослаблены):
   - `SpawnTests.S09_S8_5_Day_Limit5_In2Minutes` — удалён: правило «днём лимит 5» отменено словом Автора; на его месте `C006_Day_TenMinutes_ZeroSpawns` (строже: ни одной новой сущности за 10 мин). Ночной лимит проверяет `S09_S8_5_Night_Limit8` (не тронут).
   - `S09_S8_5_NoSpawn_OnBuiltFloor` — сценарий перенесён на ночь: днём появлений нет вовсе, проверка «пол запрещает» была бы пустой; ночью — настоящая.
   - `S09_S8_8_Far90_Despawn_AtTick900`, `S09_S8_8_Far70_NoDespawn`, `S09_S8_8_ChunkOutsideZone_OneTick` — время на ночь: днём поставленный враг без цели уходит за 1 с, правило 8.8 проверяется ночью теми же числами.
   - `S09_S8_8_WithTarget_Exempt_ThenDespawn` — время на начало сумерек: днём с целью уходит через 30 с светлого времени (сценарий сломан бы правилом C-006), ночью радиус зрения/потери ×1,5 меняет сценарий «упёрся у стены — сдался ~675» (не исчез к 1700); сумерки — 1800 тактов без появлений и с множителями ≈ ×1, ближе всего к прежнему дневному сценарию. Пороги 900/1700 те же.
   - `NightBotsTests` (1.5/1.6, `D08_3_1`) не правились: спавнер включается до ночи, враги приходят ночью; после рассвета уходят — бот ждёт рассвета, проверки «урон за дверью», смертей — те же.
