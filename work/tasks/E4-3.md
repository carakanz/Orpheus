# E4-3 — мир и персонажи целы после перезапуска и после обрыва записи

**Ссылки:** модуль `work/modules/save.md` (читать перед шагом; модуль заморожен); `work/modules/net.md`
(характер уходов: обрыв связи, выход, вытеснение).

## Зачем
Шаг 4.3 плана (`work/PLAN.md`, этап 4 «вдвоём по сети»); приёмка **А**. Формат сейчас 17 (E3-3b).
После этапа 3 в сейве появились: личная капля (`PileField.Owner`), стрелы-кучи, добыча, луки,
очереди крафта, сундуки, постройки на сетке 0,5. Сквозной проверки «полный цикл игры →
перезапуск → всё на месте» нет; есть только частичные тесты по формам (форматы 6…17).
Разблокирует: 4.4 (приёмка вдвоём).

## Что делаем
1. **Сквозной тест перезапуска** (`tests/Orpheus.Tests/`, на настоящем `ServerHost`, как `C005_Craft_…`):
   сгенерировать мир → оба игрока играют (добыча, крафт в очереди, сундук с содержимым, постройки
   0,5, личная капля с владельцем, кровать как точка возрождения) → сохранение → **убить процесс
   сервера** → старт нового сервера на той же папке → вход обоих → хэш состояния совпадает
   с хэшем до падения; содержимое сундуков, очередь крафта (сворачивается в сумку — правило E2-3),
   позиция, сумка, кровать, владелец личной капли — на месте.
2. **Обрыв записи**: смоделировать падение посреди записи (прерванная запись временного файла:
   обрезать/оставить `*.tmp`, удалить переименование) → сервер стартует, берёт **прежний** файл,
   мир читается, ничего не «полуприменено»; второй вариант — битый основной файл (обрезанный) →
   понятная ошибка в логе и запасной/прежний путь по существующему поведению (как сейчас — записать
   в «Решения»).
3. Если тест вскрывает реальную потерю данных — чинить в `src/Orpheus.Save/` (формат при этом не
   менять, если достаточно порядка/атомарности; если формат трогать нужно — следующий номер +
   тест на настоящий файл прошлой версии + строка в `work/modules/save.md`).

## Готово, если
- Тесты зелёные: `dotnet test --filter "FullyQualifiedName~E43"` (число тестов в карточку); обычный
  CI не сломан (`tools\ci.ps1`, зелёное мерить `Failed: 0`).
- В карточке — числа: хэш до/после перезапуска (совпали), что именно проверено на сохранность
  (сундук N ячеек, очередь M позиций, построек K, капель с владельцем L).
- `-All` один раз перед слиянием (карточка трогает сохранения): падают только тесты из `work/flaky.md`, прошедшие поодиночке.
- `reviewer` (П) принято.

## Правила
Модуль `save` заморожен: только починка фактической дыры. Атомарная запись (временный файл →
сброс на диск → переименование) не ослабляется; отложенная запись запрещена. Старый файл обязан
читаться. Пороги не ослаблять, `Assert` не удалять. Тесты не пишут в реальные папки Автора —
только во временные каталоги. Сети — `127.0.0.2`, `--public` никогда. Дочерние процессы — скрытый стол.
