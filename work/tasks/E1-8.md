# E1-8 — тон суток: день/сумерки/ночь/рассвет + свет факела и костра (план: шаг 1.8)

**Модуль:** `daylight` (снимает слой с `worldview`). **Ветка:** `task/E1-8` (рабочая копия `.claude/worktrees/te18`). **План:** `work/PLAN.md`, этап 1.

**Цель:** на снимках одной точки видно четыре фазы суток (день, сумерки, ночь, рассвет) — различимы по тону и яркости; ночью у факела и костра светло (круг света), в лесу ночью темнее, чем на лугу.

## Что сделано

- **Ядро `DayTint`** (`src/Orpheus.Core/World/DayTint.cs`): L тайла для рендера = `LightIndex.LightX1024` (фон × k + источники), только k берётся по полу тайла: лесная подстилка → поправка леса (870), остальные полы → 1024. Причина: клиент получает от сервера чанки (docs/07, 3.4), байта биома у него нет. Правила (порог видимости, спавн) считают `LightIndex` по настоящим биомам — это визуальная approximation до передачи биома в протокол. `DarknessX1024` = 1024 − L (с зажимом).
- **Тесты `DayTintTests`** (5): k по полу; факел ночью → L = 1024 (внутри r0), за радиусом → фон 307; костёр светит лесу ночью (лес 260 < 277 — невидим без света, у костра 1024); четыре фазы дают разные L (ночь < сумерки/рассвет < день), лес темнее луга в каждой фазе; зажим темноты.
- **Клиент `DayTintView`** (`client/Assets/Scripts/DayTintView.cs`): полноэкранный SpriteRenderer-квад (дочерний камеры, sortingOrder 1000) с сеткой тайлов прямоугольника камеры: текстура ARGB32, R = k (k >> 2), G = свет источников `SourceLightX1024` (s >> 2), билинейная — свет факела/костра кругом, без клеточных границ. Сетка перестраивается по штампу (геометрия камеры + ревизии чанков под rect); фон, цвет и альфа — униформы каждый кадр.
- **Шейдер `Orpheus/DayTint`** (`client/Assets/Resources/DayTint.shader`): альфа = (1 − L) × `_Max` (0,78 — полная тьма не чернота); L = `_Bg` × R + G; цвет темноты `_Tint`: ночью холодный синий (0,02; 0,05; 0,18), в сумерках/рассвете тёплый (0,32; 0,13; 0,06) — смесь по величине фона. В `Assets/Resources` — гарантированно попадает в сборку (у Ground.shader ссылка из GroundSet.asset, у тона её нет). SpriteRenderer подставляет в шейдер текстуру своего спрайта, поэтому спрайт строится из самой сетки (extrude 0).
- **Ключ `--day-tick 0…35999`** (`ClientArgs.cs`): такт суток офлайн-снимка — у офлайна часы мира стартуют с 0 (`Simulation.WorldTime`), ключ задаёт сдвиг; в сети игнорируется (время присылает сервер).
- **Врезки:** офлайн — `GameBoot` создаёт слой после постановки камеры, `Update(WorldTime + DayTick)` в кадре; сеть — `NetGame.BuildWorld` создаёт слой, `Render` обновляет по `WorldClock.TicksAt(now)` (оценка часов мира из заголовка снимков).
- **`--paint-demo`** дополнен: факелы вдоль тропинки (x = старт+3…+27, шаг 8) и костёр на восточном берегу озера — видно «дырки» света ночью.
- **Заглушки вида:** факел и костёр рисуются валуном (`WorldView.ObjectTile`), свои спрайты — 1-024.
- **Стенд:** сцены 13–16 в `tools/shots.json` — одна точка у озера [509, 512], обзор 40, `--paint-demo --day-tick` = 10800 (день) / 22500 (середина сумерек) / 28800 (ночь) / 35100 (середина рассвета).

## Решения

- **k биома для рендера — по полу, а не по байту биома:** у клиента нет биома в протоколе (docs/07, 3.4); лесная подстилка есть только в лесу — приемлемая approximation. Передача биома в протокол — отдельное решение, не этой карточкой. `[док]`
- **Фон тона — униформа, а не в сетке:** фаза суток меняется каждый кадр, геометрия камеры — редко; так перестройка текстуры — только при движении/правке.
- **Тёмный слой поверх всего (sortingOrder 1000), а не затемнение тайлов:** не трогает меш земли и Tilemap, работает на всех видах сразу; персонаж и существа тоже под тоном (ночью силуэты — 01, 6).
- **Максимальная тьма 0,78, не 1,0:** полностью тёмный тайл остаётся читаемым силуэтом (порог 0,27 в формуле — «пол силуэтом», не чернота).
- **`--day-tick` — сдвиг офлайн-часов, не установка:** `Simulation.WorldTime` идёт тактом; снимки стоят — сдвиг постоянен. Сеть не трогается.

## Что ещё плохо (честно)

- Свет источников ночью «квадратно-сеточный» на максимальном зуме (шаг сетки 256 тайлов); на обзоре 40 один тайл сетки < пикселя экрана — гладко.
- Факел/костёр — валуны (до 1-024); свет есть, источника-картинки нет.
- Звери/персонаж под тоном целиком (и у костра тоже) — подсветка персонажа у огня не делается (шаг с тенями/2D-светом — не этот).
- k по полу: поляна внутри леса (трава) освещена как луг — заметно только в лесу ночью; настоящий биом придёт с протоколом.
