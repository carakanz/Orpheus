# 0-031 — режим «сервер в потоке» и `IPlatformStorage` для клиента

**Поток:** Я (`ServerHost`, локальная связь) + М (сохранения через `IPlatformStorage`) + К (клиент Unity). **Ветка:** `task/0-031` (рабочая копия `.claude/worktrees/t031`). **Веха:** 0, платформенный слой (неделя 11).

**Зависимости:** **после слияния 0-024** (запуск сервера из клиента, ключи, режимы клиента) **и 0-025** (цикл такта, часы, заморозка в `ServerRun`); желательно после 0-030 (метрики такта переезжают вместе с циклом). **Параллельно можно:** с 0-027, 0-028, 0-029 (сервер в них — `NetServer`, не цикл `ServerRun`), 0-023. **Ждут эту карточку:** приёмка 0.12 (IL2CPP — после модуля, который ставит Автор).

**Цель:** `07` 1.6 и 2.3 — `ServerHost` из той же библиотеки работает в потоке игры, клиент ходит к нему через локальную связь; режим есть с первого дня и проверяется в CI. Сохранения и загрузка в этом режиме — только через `IPlatformStorage` (на ПК — `PcStorage`). На ПК по умолчанию остаётся отдельный процесс (0-024).

## Шаги

1. **`ServerHost`** — цикл сервера (такт, `NetServer`, сохранение, журнал, часы, метрики) из `Orpheus.Server` в сборку `netstandard2.1` без P/Invoke и `Console`: таймер высокого разрешения (`TickClock`, kernel32) — за интерфейсом платформы с реализацией «ПК»; лог — в `TextWriter`/приёмник. `OrpheusServer` — тонкая оболочка над `ServerHost`; поведение и ключи не меняются (тесты сервера зелёные без правок).
2. **Локальная связь** без выделений на пакет (backlog): пул буферов в `LoopbackTransport`; тест в `AllocationTests`. Потокобезопасность: сервер в своём потоке, клиент — в потоке игры; очередь между ними — без блокировок на каждом пакете (или с одной короткой — записать).
3. **Сохранения через `IPlatformStorage`:** `ServerHost` получает хранилище снаружи (на ПК — `PcStorage`); никаких прямых `File.*` в пути сохранения и загрузки (тест или анализатор).
4. **Клиент Unity:** режим «сервер в потоке» ключом (`ClientArgs`): `ServerHost` в потоке, клиент — через локальную связь тем же `NetClient`; сохранение и загрузка — через `PcStorage`. DLL `Orpheus.Server`-ядра (новой сборки), `Orpheus.Save`, `Orpheus.Platform.Pc` — в `Assets/Plugins/Orpheus` скриптом сборки.
5. **Тест CI без Unity** (`D07_S1_9_5_*`): `ServerHost` в потоке + `NetClient` по локальной связи — N тактов (ускоренно), такт держится (отставание ≤ 3 тактов), автосохранение через `IPlatformStorage` (`PcStorage` во временной папке и хранилище в памяти), загрузка заново — хэш мира тот же.
6. **Unity Mono:** «сервер в потоке» — одиночная игра 10 мин в пакетном режиме (`--smoke`-сценарий), такт держится, сохранение и загрузка проходят; IL2CPP — когда Автор поставит модуль (`work/next.md`, «Ждёт Автора»), тогда же 0.12 целиком.
