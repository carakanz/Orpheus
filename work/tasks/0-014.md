## Шаги

1. Протокол: в заголовок снимка — флаг «дельта» и такт базы; в теле дельты — список удалённых id (16 бит) и изменившиеся сущности (как в полном). `Snapshot` несёт `IsDelta`/`BaselineTick`; ридер/писатель — тесты round-trip.
2. Сервер: на игрока — последнее отправленное состояние (id → позиция/направление/вид) + флаг «нужен полный». `SendSnapshots`: полный — контрольный кадр каждые `KeyframeTicks` (30 тактов = 1 с), по запросу клиента, первому снимку и при переполнении бюджета; иначе дельта (изменилось/появилось/удалилось). Счётчики: байты полных/дельт.
3. Клиент: склейка — дельта к базовому полному по такту базы; не сходится (пропуск) → просим полный (бит 0 кнопок ввода), следующие снимки игнорируем до полного; счётчики склеек/запросов. `Latest`/кольцо — полные склеенные, интерполяция не меняется.
4. Тесты: кодек дельты round-trip; loopback 2 бота — финальные позиции как на полных, байт/снимок ниже полного, потеря снимка → восстановление ≤ 1 с (контрольный кадр); 8 игроков в бюджете.
5. Приёмка вживую: сервер + Unity net-smoke (позиция, расхождение предсказания, `[smoke] done`), офлайн `--smoke`, CI, сборка Mono, скриншот.
