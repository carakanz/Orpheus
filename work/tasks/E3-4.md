# E3-4 (шаг 3.4) — враги и удары видны: замах, попадание, смерть, снаряд

Модуль: `actors`. Ветка `task/E3-4`, копия `.claude/worktrees/te34`. План — `work/PLAN.md` этап 3, шаг 3.4 (готово: С — «лента кадров»). Ядро, протокол, сохранения не трогаем — только клиент (картинка).

## Что сделать
1. **Враг выглядит врагом.** Snapshot-враги (`KindEnemy`) в `NetGame.GetEntity` сейчас рисуются спрайтом героя с голубым тинтом, как чужие игроки. Дать врагам отдельный процедурный вид (как `ActorFactory.EnemyTint` у манекенов, тёплый красный) и меч в руке (`ActorRig.SetHeld`); архетип врага есть в снимке (`SnapshotLayout.EnemyArchetypeShift`) — для известного архетипа (1 = мечник) свой оттенок/мелочи, 0 — общий враг.
2. **Убрать двойную отрисовку.** `SwingStartMessage` создаёт в `NetAnimation._enemies` корень `Enemy {id}` (манекен 0-029) с полным спрайтом — для реального snapshot-врага это второй спрайт рядом с `Ent {id}`. Для врага, у которого есть спрайт снимка, у призрака оставить только сектор-телеграф (спрайт скрыть); позиция и фаза — как сейчас.
3. **Попадание по врагу** (сообщение 37, жертва — враг): красная вспышка/отдача сейчас только у `_remotes` (`OnRemoteHit`) — завести на вражеские корни; смерть/растворение (`DeathAnim`, E3-1) проверить на snapshot-враге.
4. **Силуэт за кроной** (из «Дальше» модуля): враги и чужие игроки видны сквозь крону, как свой (`Objects.shader` `_OrphHero` → слоты существ, `WorldFx` их заполняет).
5. **Лента кадров**: сцена в `AnimShowcase.cs` (замах врага → попадание по герою → удар по врагу → смерть врага → полёт снаряда врага) + записи в `tools/shots.json`; снимки в карточку, каждый кадр посмотреть.

## Решения (предварительные)
- Вид врага — процедурный из кода (слово Автора: анимация процедурная, ассеты потом): спрайт героя + тёплый красный тинт (`ActorFactory.EnemyTint`), меч из значков предметов; архетип 1 (мечник) — базовый вид, 2/3 (лучник/зверь) — появятся в 3.3, тогда же оттенок. [док] точный силуэт врагов — дизайн-сессия 3.0.
- Призрак `Enemy {id}`: `SwingStartMessage` не знает, есть ли у id спрайт снимка, — решение на стороне кадра: если в этом кадре у snapshot-врага есть корень `Ent {id}`, спрайт призрака скрыт, сектор рисуется от места корня снимка.
