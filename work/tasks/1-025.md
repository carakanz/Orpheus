## Шаги

1. **Сценарий `fight`:** бот выбирает ближайшего врага, подходит и бьёт мечом (или держит дистанцию и стреляет из лука — режим ключом), уворачивается по замаху ближнего и по выстрелу стрелка (с направлением, по слову Автора); пишет журнал: нажатия уворота, «в окне замаха», засчитано сервером; удары «попал на экране» / засчитано.
2. **Прогоны** имитатором связи (UDP на петле и режим симуляции): RTT 200, σ 20 мс пачками, потери 1 % (1.1); RTT 100, 250, 300 (1.2); RTT 600 (1.3). Несколько врагов внахлёст (2 ближних + 1 стрелок).
3. **1.7:** два клиента по разные стороны шва; стрела одного через шов во врага за швом; второй видит полёт и попадание (запись появления и «погас — попадание» в его снимках + снимок экрана Unity).
4. **Замер такта:** 8 ботов `fight` + враги по правилам появления 1-009 ночью на 1024², 10 мин, UDP, Release — средний такт, p99, доля ИИ и поиска (метрики 0-030).

## Чек-лист приёмки

- [ ] 1.1: RTT 200, σ 20 мс пачками, потеря 1 % — из 1000 нажатий уворота бота не потеряно ни одного.
- [ ] 1.2: RTT 100, 250, 300 — уворот, нажатый за ≥ 17 мс до конца показанного замаха, засчитан в ≥ 95 из 100; удар мечом, попавший на экране, — ≥ 95 из 100. Каждый — на ≥ 3 зёрнах имитатора.
- [ ] 1.3: RTT 600 — уворот за ≥ 0,1 с до конца замаха — ≥ 90 из 100.
- [ ] 1.7: стрела через шов попадает во врага за швом; товарищ по ту сторону видит полёт и попадание (`work/screens/1-025_seam_arrow.png`).
- [ ] Замахи внахлёст (3 врага): уворот засчитан ≥ 95 из 100 при RTT 200 (или числа и строка backlog про D_p закрыты).
- [ ] Такт: 8 ботов + враги ночью — средний ≤ 10 мс (`07` 9.8 / `08` 0.9); числа и доли в карточку.
- [ ] Мутации (≥ 2): «без ожидания W», «без отмотки» — соответствующие строки таблицы краснеют.
- [ ] Короткие версии приёмок (по 20 попыток) — в `tools\ci.cmd` ≤ 60 с суммарно; полные — `-All` / `Soak`.
