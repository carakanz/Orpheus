# D-004 — двухмерные скелеты для монстров: шаблоны по типам тела (проба на разбойнике и волке)

Модули: `actors`, `art`. Ветка `task/D-004`, копия `.claude/worktrees/td004`. Обсуждение с Автором 21.11 (BRIEF 11o): анимация монстров — «двухмерный скелет по готовой картинке» (вырезка: части тела на костях, как Darkest Dungeon / Hollow Knight); шаблоны по типам тела.

## Вопросы Автора (21.11) и ответы Producer — ждут подтверждения Автора
- «Человекоподобные — есть готовые шаблоны?» — покупных не берём (они под чужую графику); делаем **свой один шаблон** человека, он подходит ко всем человекоподобным — задача простая и проверенная.
- «Четвероногие — тоже есть?» — да, **свой один шаблон** четвероногого.
- «Многоногие — можно пока выкинуть?» — да, можно: их 15 из 288, отложить без ущерба.
- «Циклопы и титаны — скелет людей?» — да, тот же скелет человека, крупнее.
- «Цербер, гидра — взять человека и доделать?» — **лучше не человека**: Цербер — шаблон четвероногого + 2 доп. шеи с головами; гидра — тело четвероногого/змеи + цепочки-шеи (как змея). Человек для них не подойдёт по пропорциям.
- Аморфные (слизи, духи, рои) — без костей, кодом/шейдером; змеи/лозы/щупальца — цепочка сегментов.

## Шаг 1 — проба (разбойник-мечник и волк)
1. Мак (ComfyUI, `tools/art_a006.py` как образец): каждый в **ракурсе как у стен** (сверху под небольшим углом) и в **нейтральной позе для анимации** (руки/ноги отведены от тела, ничего не перекрыто), 3 направления (front/back/side), — или лист частей тела по отдельности; скрытые места — дорисовать (inpaint).
2. Нарезка на части (полуавтомат: сегментация + доводка), сборка скелета **скриптом** (иерархия спрайтов на костях; мягкий изгиб 2D Animation — по желанию, если надёжно).
3. Анимации кодом: ходьба/бег, удар (мечник), рывок-укус (волк), попадание, смерть; 4 направления (влево — отражение).
4. Лента кадров (скрытый стол) + снимок в игре ночью; сравнить с нынешними заглушками C-053. **ЖДУ АВТОРА** по ленте — не масштабировать на остальных до его слова.
