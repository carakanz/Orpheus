# C-028 — добыча: камня ×4, кирка бьёт горизонтально и ломает несколько камней

Модули: `combat`/добыча, `items`, `actors`. Ветка `task/C-028`, копия `.claude/worktrees/tc028`.

## Что сделать

1. **Камня выпадает в 4 раза больше** (каменные тайлы/валуны → дроп ×4; проверить, что рецепты не стали тривиальными — отметить в карточке).
2. **Удар кирки горизонтальный** (замах вбок, как меч, к курсору), **ломает сразу несколько каменных тайлов в направлении удара** — например, 3 тайла в секторе/линии длиной 2–3 тайла от персонажа (числа предварительные).
3. **На один камень нужно несколько ударов** (стандартная — каменная — кирка: 3 удара на камень, медная — 2; прочность тайла накапливается, видна трещинами; урон по тайлу копится и сбрасывается через N с без ударов). Это меняет нынешнее «копание по времени» (`DigFrames`) — согласовать с ядром детерминированно, предсказание клиента, сеть.
4. Анимация удара киркой — горизонтальный взмах (`Anim/`, как меч C-012), отклик по каждому затронутому тайлу.
Деревья/топор — не трогать (если Автор не просил), но общий механизм «прочность тайла» сделать общим.

**Сделано** (ветка `task/C-028`, копия `.claude/worktrees/tc028`):
1. **Камень ×4**: скала и гранит — 4…8 камня (было 1…2; `DigLoot.StoneDropMul` = 4) [док] к `06` 1.4. Медь не менялась.
2. **Взмах кирки** (ядро `World/PickStrike.cs`, целые числа, общий для сервера, предсказания и ботов): с киркой ЛКМ к пустому или природному тайлу — взмах к курсору 24 кадра (0,4 с), удар в последний кадр. Удар задевает до **3** «каменных» тайлов (природный объект, который эта кирка берёт) в секторе **±45°** от оси «персонаж → центр тайла прицела», ближняя точка тайла ≤ кирка + 1 т (≈ 2,15 т): тайл прицела — первым, дальше по близости. По стене скал — прицел и два по дуге; по коридору — 1-й и 2-й по линии. Постройки киркой — прежний снос по времени; топор, молот, деревья — без изменений.
3. **Несколько ударов на камень**: общий механизм прочности тайла `World/TileWear.cs` (удары по тайлу общие у всех игроков; сброс через **5 с** без ударов и при смене объекта; не сохраняется). Ударов — `DigTimes.HitsFor` = ⌈3 × модификатор ÷ (100 << ярус выше нужного)⌉: скала каменной **3**, медной **2**; залежь 6 / 3; гранит медной 5 (каменной — «нужна кирка: медная»). Числа — *прикидка*.
4. **Сеть, протокол 32**: «взмах» (39) — ударившему и игрокам в 56 т (тайлы, удары/нужно, «снят»); ответ на запрос взмаха — «принято», маска: бит 31 + снятые тайлы. Время — по кадрам сервера (как копание). Клиент: трещины своих ударов — сразу своим счётом (`NetClient.Strike.cs`), снятие камня не предсказывается (удары общие — добил тот, чью правку принял сервер), тайл уходит пачкой мира. Начатый взмах доигрывается; зажатая ЛКМ — взмахи подряд без ожидания ответа.
5. **Клиент**: кирка — горизонтальный взмах вокруг прицела, как меч (головка от прицел + 75° до прицел − 75°, `ActionAnim`), отклик — искры и крошка на каждом задетом тайле (свои — по своему удару, чужие — по «взмаху»), искры поверх валуна (`Sparks.Order`); трещины `TileCracksView.cs` (3 стадии по доле ударов).
