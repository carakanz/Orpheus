# C-028 — добыча: камня ×4, кирка бьёт горизонтально и ломает несколько камней

Модули: `combat`/добыча, `items`, `actors`. Ветка `task/C-028`, копия `.claude/worktrees/tc028`.

## Что сделать

1. **Камня выпадает в 4 раза больше** (каменные тайлы/валуны → дроп ×4; проверить, что рецепты не стали тривиальными — отметить в карточке).
2. **Удар кирки горизонтальный** (замах вбок, как меч, к курсору), **ломает сразу несколько каменных тайлов в направлении удара** — например, 3 тайла в секторе/линии длиной 2–3 тайла от персонажа (числа предварительные).
3. **На один камень нужно несколько ударов** (стандартная — каменная — кирка: 3 удара на камень, медная — 2; прочность тайла накапливается, видна трещинами; урон по тайлу копится и сбрасывается через N с без ударов). Это меняет нынешнее «копание по времени» (`DigFrames`) — согласовать с ядром детерминированно, предсказание клиента, сеть.
4. Анимация удара киркой — горизонтальный взмах (`Anim/`, как меч C-012), отклик по каждому затронутому тайлу.
Деревья/топор — не трогать (если Автор не просил), но общий механизм «прочность тайла» сделать общим.
