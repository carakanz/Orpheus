## Решения
- Маркер завязан на тайл (W/2,H/2): Очаг — не ObjectId (E3-6 «Решения»), клиент знает центр из `accept.MapWidth/2, MapHeight/2`
  (NetGame) и `Args.Size/2` (GameBoot, спавн = центр).
- Проводка в обоих путях (NetGame + GameBoot): smoke проверяет сетевой путь, снимки идут офлайн — без GameBoot кадр был бы без маркера.
- Пульс по `now` мкс (NetGame) / накопленным фиксированным часам (GameBoot) — кадры снимков детерминированны.
- Smoke-проверка видимости маркера добавлена (усиление, пороги не ослаблялись).
- Ночная сцена — полный кадр без кропа: тон ночи — градиент по высоте экрана, центральный кроп даёт «день»;
  правка только в shots.json (комментарий в сцене).
- Первый визуальный проход (12 камней 0.5t @ R=0.30, свечение alpha 70-125) глазами бракован: серый «бублик», сизое свечение;
  переделано на 10 двухслойных камней @ R=0.62 + тёплое свечение 1.35t alpha 120-200.
