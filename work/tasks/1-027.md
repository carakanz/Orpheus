# 1-027 — сборка для игры Автора: вход по IP, журналы уворотов, приёмки 1.4 и 1.9

**Поток:** К (сборка, меню входа) + Я (журналы и подсчёт). **Ветка:** `task/1-027` (рабочая копия `.claude/worktrees/t1027`). **Веха:** 1 «Прототип» (`08` 3.1, неделя 22).

**Зависимости:** после слияния всех карточек вехи 1 с кодом игры: **1-001…1-021**, **1-023**, **1-025**, **1-026** (1-022 и 1-024 — тоже, если их итоги в игре). **Параллельно можно:** правки по итогам 1-025 / 1-026. **Ждут эту карточку:** приёмка вехи 1 (недели 23–24).

**Цель:** Автор и второй человек играют две сессии по 30 мин на настоящей задержке без консоли разработчика: копают, строят хижину с дверью, переживают ночь, убивают ≥ 10 врагов. По журналам ввода считается доля засчитанных уворотов. Приёмка 1.4 — второй игрок входит по IP в мир хоста без перезапуска.

**Ссылки:** `docs/08_roadmap.md` 3.1 приёмки 1.4, 1.9, «Показываем Автору», «Зависимости» (второй человек — В44, настоящий RTT — В32), 7.6 (как Автор играет и даёт обратную связь); `docs/07_multiplayer_tech.md` 2.3 (сервер хоста из командной строки, второй игрок по IP), 10.1, 11.6 (логи и метрики), 2.13 п. 9; `BRIEF.md` п. 11b («Открыть для друзей» — ок, потом допилим; пауза у любого игрока — 0-036; хост падает — тот же персонаж, 0-035). Код: `client/Assets/Scripts/GameBoot.cs`, `ClientArgs.cs`, `LocalServer.cs`, `tools/build_client.ps1`, `tools/playable.ps1`.

## Шаги

1. **Меню входа** (заглушка UI): «Одиночная», «Хост» (мир 1024² из генератора, порт, `--public`), «Подключиться по IP» (адрес, порт, имя — обязательно в сети, `BRIEF.md` п. 14a); без консоли разработчика. Пауза — по 0-036.
2. **Журнал боя** у сервера: каждое нажатие уворота с номером кадра, было ли оно в окне показанного замаха, засчитано ли; удары «попал на экране» (от клиента) и засчитано; убийства. Инструмент подсчёта по журналам обеих сессий (`tools/` — скрипт).
3. **Сборка** Windows (Mono; IL2CPP — если модуль поставлен Автором) и папка `playable/` с инструкцией на одну страницу: как запустить хост, как дать адрес другу, что делать (копать, строить хижину с дверью, пережить ночь, убить 10 врагов), куда смотреть после — три вопроса Автору.
4. **1.4:** сервер хоста, запущенный командой, принимает второго клиента по IP с другой машины (или виртуальной — Hyper-V); мир не перезапускается.
5. **Прогон без людей** перед передачей: 2 бота 30 мин на этой сборке, RTT 200 — 0 падений, журнал считается.
