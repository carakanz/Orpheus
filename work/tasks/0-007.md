# 0-007 — генератор-заглушка мира на торе

**Поток:** М (мир). **Ветка:** `task/0-007` от `main`. **Веха:** 0, недели 1–2.

**Цель:** `Orpheus.WorldGen` создаёт мир 1024² и 4096² по зерну: целочисленный шум, бесшовный на торе по обеим осям, два поля (луга и скалы), деревья и скалы как объекты; результат — снимок генерации `WorldSnapshot` (0-005).

**Ссылки:** `docs/07_multiplayer_tech.md` — 3.4 (генерация и «снимок генерации + изменения»), 11.5 (повторяемость: свой генератор, SplitMix64, без `Math.Sin` и `System.Random`); `docs/01_world.md` раздел 2 — только этап полей (не весь генератор); `docs/08_roadmap.md` 3.0 строка «Генератор-заглушка»; опора по скорости — `design_room/threads/00_vision/noise_bench/result.md`; `work/refs/world.md`.

## Шаги

1. Целочисленный шум (value noise или simplex в фиксированной точке — выбери и обоснуй одной строкой), периодический по ширине и высоте мира (без шва), октавы; только целые числа или фиксированная точка, анализатор ядра чист.
2. Этап полей: доля скал ≈ 25 % *(прикидка, константа в одном месте)*, остальное луга; деревья на лугах и скалы-объекты — по шуму плотности и хэшу тайла (SplitMix64), с минимальным расстоянием 1 тайл.
3. `IWorldGenerator` + реализация `StubGenerator`; результат — `WorldSnapshot`/`WorldModel` из 0-005, версия генератора в снимке (`07` 3.4).
4. Стартовая зона: 32 × 32 тайла вокруг центра — без скал и деревьев (чтобы боты и игрок не застревали).
5. Тесты `D00_Gen_*`: одно зерно → побайтно один мир (два прогона); разные зёрна → разные миры; бесшовность — шум на краях совпадает с соседями через шов (разность соседних значений через шов в том же распределении, что внутри); доля скал в допуске ±3 %; стартовая зона чиста.
6. Замер: время генерации 1024² и 4096² на машине разработчика (в карточку, против `noise_bench`); тест 4096² — `Category=Big`.
7. Картинка для глаз: `tools/gen_preview` (консоль .NET или Python по снимку) — PNG карты 1024² (луга, скалы, деревья) в `build/` (не в git), путь — в карточку.

## Решения и отклонения

- **Шум** — решётчатый value noise в Q15 (`src/Orpheus.WorldGen/TorusNoise.cs`): так велит `01` 2 «Поля шума» (узел — хэш зерна и индексов, период — степень двойки), считается сложениями и сдвигами; индекс узла по модулю числа узлов — шва нет по построению. Период октавы — min(ячейка, W/2).
- **Доля скал — по гистограмме** (порог = квантиль 75 %), а не порогом шума: так `01` 2 («доли вместо порогов»); доля держится 25,0 % ± 0,1 на любом зерне. Константа — `StubGenerator.RockSharePercent`.
- **Скалы-поле** — пол `FloorId.Stone` (проходимый), на нём густо скалы-объекты `ObjectId.Rock`; луга — `FloorId.Grass`, деревья по шуму плотности + редкие скалы. Прореживание: объект ставится, если хэш-приоритет тайла больше, чем у всех кандидатов в 8 соседях по тору, — расстояние ≥ 1 тайл, порядок обхода не важен, через шов тоже.
- **Сравнение «шов ↔ внутри»** — с внутренними границами ячеек базовой октавы: шов лежит на узле всех октав, где smoothstep плоский, поэтому сравнивать его со средним по всем столбцам было бы нечестно (на узле разности меньше).
- **Отклонение:** правлен `Orpheus.sln` (добавлен `tools/gen_preview`), `WorldGenModule.GeneratorVersion` = 1 (было 0, «генератора ещё нет»). `World/`, `Torus`, `Movement`, `Orpheus.Server`, `client/`, `docs/` не тронуты.
- Однопоточно: 4096² за 0,44 с — до нормы 30 с запас ×60, параллелить незачем.
