# C-033 — шлюз чистоты процессов в `ci.ps1` (наблюдатель spawn'ов + конхост на столе Автора)

Ветка `task/C-033`, копия `.claude/worktrees/tc033`, база `main e729cf3`.
Пункт 6 `work/opencode_start.md`: «`ci.ps1` без conhost на столе Автора: прогон `dotnet test`
и `tools\ci.ps1` должны запускать все дочерние процессы скрыто (`HiddenProcess`, C-022),
проверка через `tools\watch_spawns.ps1`».

## Состав
- `tools/ci.ps1`: ключ `-Hygiene` — на время шагов build+test крутится `tools\watch_spawns.ps1`
  (сам запускается скрыто, через `HiddenCi`), по `-Filter <имя копии>`; в конце — строка
  «hygiene: …» и **падение CI, если conhost.exe появился на `WinSta0\Default`** (свои процессы).
- `HiddenCi.RunAsync` — фоновый запуск наблюдателя на скрытом столе (без труб, вывод — TSV-файл);
  остановка по `-StopFile`.
- `-SelfTest`: гард детектора — наблюдатель ловит намеренно запущенный conhost на столе Автора
  (probe-скрипт внутри копии: `Start-Process -WindowStyle Hidden` нового cmd.exe из-под `$root`);
  на сломанном детекторе (фильтр по имени копии выключен) гард красный.
- Пороги smoke/тестов не трогает; CI без `-Hygiene` — как был.

## Решения
- [док] Наблюдателя запускаем через `HiddenCi.RunAsync` (скрытый стол, stdout не нужен — TSV),
  а не `Start-Job`: job-воркеры (`wsmprovhost`) сами плодят conhost на столе Автора — детектор
  ловил бы собственный инструмент.
- Наблюдатель считает своими процессами: путь содержит имя рабочей копии, ИЛИ conhost, у которого
  родитель — из-под копии (как в `watch_spawns.ps1`).
- `build_client.ps1` (Unity, smoke, host-smoke) — GUI-приложения, conhost не плодят; замеры 14–16.11
  их чистыми назвали. В этот раз не трогаем.

## Мутации (проверяю сам)
- М1: выключить фильтр по копии (считать все conhost) → CI краснеет на собственных служебных
  conhost — детектор живой.
- М2: гард `-SelfTest`: probe cmd.exe из-под копии запускается без скрытого стола → гард должен
  его поймать; если сравнение.desktop сломать — гард красный.
- М3: `RunAsync` без скрытого стола (на столе вызова) → сам наблюдатель виден в замерах.

## Место остановки
- Реализовано: `-Hygiene` в ci.ps1 (наблюдатель через новый `HiddenCi.RunAsync` на скрытом столе,
  TSV `build\logs\spawns.tsv`, остановка по флагу + `PowerShell.Exiting`), хелперы `Read-Spawns`/
  `Get-ConhostOnDefault`, финальный вердикт (exit 4 при conhost на `WinSta0\Default`), гард в `-SelfTest`.
- SelfTest: 11/11 зелёные (10.11 probes: 1 conhost пойман). М2 (`-like '*\Default'` → мусор) →
  гард FAIL, откачено. Проба в гарде живёт 6 с: у мгновенно умирающих процессов desktop не читается (PEB).
- Дальше: боевой `-Hygiene` прогон (зелёный), М1 (намеренная закачка conhost из-под копии во время
  прогона → шлюз красный, exit 4), коммит, reviewer, слияние.
