1. **HUD** (uGUI или UI Toolkit — выбрать, записать): полоска здоровья, под ней выносливость (красная при < 25, мигает на «щёлк»), значок «высокая задержка», строка предмета в руках и материалов (из 1-002 — перенести в HUD).
2. **Числа урона** над целью по событию сервера (у всех клиентов в 30 т), белые; пул объектов, без выделений в кадре.
3. **Отклик:** вспышка цели белым 60 мс и у всех; стоп-кадр 50 мс и тряска 2 px / 80 мс — только у атакующего (по своей проверке попадания 1-005, если есть, иначе по событию); получение удара — красная вспышка 100 мс, тряска 3 px / 100 мс, виньетка при < 25 %; добивание — 80 мс / 4 px. 4. **Полоски над врагами** — доля здоровья из снимка (1-001), только у раненых.
