## Шаги

1. **Строки шва, которые зовут ОС, — под тестом** (выжили мутации m7, m8 проверки): `FlushFileBuffers` на дескрипторе только для чтения обязан вернуть отказ `ERROR_ACCESS_DENIED` — заглушка `=> true` тест не пройдёт; флаги `MoveFileExW` доходят до ОС как есть (например, без `MOVEFILE_REPLACE_EXISTING` перенос на существующий файл — отказ `ERROR_ALREADY_EXISTS`; с ним — успех). Мутации m7, m8 краснят быстрый CI.
2. **Тесты аллокаций не шумят:** `*_NoAllocations` и `*_AllocatesNothing` — в отдельную коллекцию xUnit с `DisableParallelization`, прогрев циклом, замер по `GC.GetAllocatedBytesForCurrentThread`. 20 прогонов быстрого CI подряд — 0 падений (число записать).
3. Мелкое: исключение в `finally` у `RunServer` не заслоняет исходное падение (ловить и добавлять к сообщению).
4. В `work/backlog.md`: POSIX-ветка сохранения (`fsync`, `rename`) без теста — к задаче выделенного сервера на Debian (6.10 п. 9); правило `text` для `*.asset` — если появится бинарный `.asset`, добавить исключение.
