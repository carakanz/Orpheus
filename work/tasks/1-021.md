## Шаги

1. **Текстура L** на окно чанков (1 тексель на тайл, R8), пересчёт по чанкам при смене источников и раз в несколько кадров по времени суток (фон); загрузка на GPU без выделений в кадре.
2. **Шейдер** тайлов и спрайтов: цвет × L с плавной интерполяцией между тайлами; ночной оттенок (синий, `01` 6 «Как играется»); силуэт пола при L < 0,27.
3. **Видимость существ:** враги и чужие существа на тайле с L < 0,27 не рисуются (свой, товарищи — рисуются всегда).
4. **Факел в руке** — подвижный источник у своего персонажа и у товарищей (из предмета в руках 1-002).
5. **Время на экране** — строка HUD «день / сумерки / ночь, мм:сс» (до часов-значка).
