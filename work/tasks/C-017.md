# C-017 — тени по солнцу и от факелов; закрытые комнаты

Модули: `worldview`, `daylight`, `building` (+ `sim` для комнат). Ветка `task/C-017`. **Старт после слияния C-016** (те же `ObjectMesh`/`WorldFx`/тени). Слова Автора 15.11, дословно:
> Тень должна проворачиваться в зависимости от времени суток. Для этого для предметов сделай тень во 4 стороны и дальше в зависимости от дня эти прямоугольники превращай в параллелограммы и поворачивай. Если есть идеи получше — говори. В закрытых помещениях тени от солнца быть не должно. Должны быть тени от факелов. В случае нескольких источников высчитываться. Тень за стены попадать не должна.
> Для врагов пусть по старому. Вокруг окружённого со всех сторон стенами факела не появляются.

Предложение Producer'а принято вместо «4 сторон»: одна тень-силуэт на предмет, сдвиг/наклон в вершинном шейдере по общему вектору солнца (плавно, почти бесплатно); у построек — объём (низ + верх, сдвинутый по солнцу → параллелограмм).

## Что сделать
1. **Солнце.** Вектор солнца от такта суток (с сервера): восход — тень длинная на запад, полдень — короткая на север, закат — длинная на восток; сумерки — бледнеет; ночь — солнечной тени нет. Числа (длина ×высота, азимут) — в таблице `DayTintView`/новой `SunTable`, помечены как предварительные. Деревья, кусты, валуны, персонажи, враги, постройки, кучи — все через один механизм; тень гор — тоже (длинная вечерняя).
2. **Закрытые комнаты.** Область, замкнутая стенами/дверями (сетка 0,5, тонкие стены 2.12; открытая дверь не размыкает комнату) — поиск заливкой, кэш по чанкам, пересчёт при правке стены/двери. Внутри комнаты солнечной тени нет; солнечная тень снаружи обрезается по стенам и в комнату не заходит.
3. **Тени от факелов/костров.** Видимость источника с учётом стен (луч/видимость на сетке 0,5, только для картинки): свет за стену не проходит. Каждый предмет отбрасывает тень от каждого из 2–3 сильнейших ближних источников, прочь от источника, темнота ∝ вкладу источника; несколько источников — несколько бледных теней. Тень за стену не попадает.
4. **Враги (ядро).** Освещённость для появления врагов — **по-старому** (`LightIndex` без учёта стен). Новое правило: в замкнутой стенами области, где есть факел/костёр, враги не появляются (комнаты из п. 2 — в ядре, детерминированно; без пола тоже). Тест ядра; правило в `work/modules/daylight.md` `[док]`.
5. Производительность: кадры/с на обзоре 64 днём и ночью с 10 факелами — не хуже −10 % (замер до/после в отчёте).

## Готово, когда
- Снимки (скрытый стол, монитор 2): утро/полдень/вечер у дома и леса, комната днём (без солнечной тени внутри), комната ночью с 2 факелами (две тени), тень не лезет за стену → `work/screens/C-017_*.png`; исполнитель сам смотрит каждую.
- Тесты: комнаты (замкнута/дыра/открытая дверь), правило появления врагов; быстрый CI зелёный (кроме `work/flaky.md`); NightBots/D08_3_1 — один раз; сборка `-Smoke -HostSmoke` код 0.
- Модули обновлены; если сейв/протокол меняются — следующие номера.

## Решения
- Тень по солнцу — одна тень-силуэт, сдвиг верха в вершинном шейдере (`uv2.x` — «солнечная высота» точки, `_OrphSun.xy` — вектор солнца из `SunTable`); у построек и гор — объём (`ObjectMesh.Prism`: верх на высоте + боковые грани; у гор — только рёбра к более низкому соседу). Числа `SunTable` — предварительные.
- Полдень: тень короткая (0,42 на тайл высоты) строго на север — по словам Автора; в наклонном виде она почти вся под кроной/предметом (видна узкой полосой у ствола). Если Автору мало — сдвинуть полуденный азимут к северо-востоку или добавить пятно у ствола. `[вопрос Автору]`
- Комната — связная (4 соседа) область ячеек 0,5, замкнутая **стенами и дверями** (открытая дверь не размыкает); **забор — не стена** (сквозной); рамка ≤ 64 ячейки (32 тайла), иначе «открытое место»; отсутствующий чанк / край плоской карты — «снаружи». Пол не нужен.
- Свет для картинки (`LightSight`, ядро, целые): стена, **закрытая** дверь и **скала** не пропускают свет; открытая дверь — пропускает. Правила врагов — `LightIndex` без стен, по-старому.
- Враги: новое правило ядра — тайл с ячейкой в комнате с факелом/костром — не место появления (`Spawner.IsSpawnTileOk`). Протокол и сохранение не менялись (комнаты — вычисляемые, в сохранение не идут).
- Тени от огня: предметы — меш чанка на CPU (источники неподвижны), пересборка по штампу окна 3 × 3; существа — каждый кадр (2 источника). Тень не длиннее пути до первой стены по лучу (`LightSight.FreeRun4`) и видна только там, куда свет доходит с учётом стен (G сетки) — за стену не попадает ни изнутри, ни снаружи. Стены и горы теней от огня не отбрасывают — за ними и так темно (свет не проходит).
- Сетка тона `DayTintView` — по ячейкам 0,5 (вместо тайлов): свет с учётом тонких стен и маска комнаты без размытия (маска берётся точкой — край солнечной тени ровно по стене).
- Сцены `--home-demo torches|room|wall`; `ORPH_SHOT_BENCH` теперь рисует и камеру теней каждый кадр (иначе её цена не входила в замер) и пишет CPU слоя теней.

## Отчёт исполнителя
**Сделано.** (1) Солнце: `client/Assets/Scripts/SunTable.cs` (такт суток → азимут/длина/сила, предварительно), шейдер `Shadow` сдвигает верх силуэта по `_OrphSun` — деревья, кусты, валуны, мебель, постройки (объём), горы (объём, длинная вечерняя), существа и кучи (`ActorShadow.cs`: пятно у ног + силуэт по солнцу; у кучи — низкий, 0,35). Ночью солнечной тени нет, сумерки/рассвет — бледнеет/проявляется. (2) Комнаты: `src/Orpheus.Core/World/RoomIndex.cs` + `CellWindow.cs` (окно 3 × 3 чанка на сетке 0,5, кэш по ревизиям); в комнате солнечной тени нет, снаружи она обрезана по стене (маска B сетки `DayTintView`, точкой). (3) Огонь: `src/Orpheus.Core/World/LightSight.cs` (свет с учётом стен, только для картинки), круг света факела не проходит за стену/закрытую дверь; тени от огня — `ObjectMesh.Fire.cs` (до 3 источников на предмет, темнота ∝ вкладу) и у существ (2 источника, каждый кадр); тень не длиннее пути до стены и видна только там, где свет источника. (4) Ядро: в комнате с факелом/костром враги не появляются (`Spawner.IsSpawnTileOk`), освещённость — по-старому; `daylight.md` `[док]`. Протокол 29 / сохранение 13 — без изменений.
