# C-017 — тени по солнцу и от факелов; закрытые комнаты

Модули: `worldview`, `daylight`, `building` (+ `sim` для комнат). Ветка `task/C-017`. **Старт после слияния C-016** (те же `ObjectMesh`/`WorldFx`/тени). Слова Автора 15.11, дословно:
> Тень должна проворачиваться в зависимости от времени суток. Для этого для предметов сделай тень во 4 стороны и дальше в зависимости от дня эти прямоугольники превращай в параллелограммы и поворачивай. Если есть идеи получше — говори. В закрытых помещениях тени от солнца быть не должно. Должны быть тени от факелов. В случае нескольких источников высчитываться. Тень за стены попадать не должна.
> Для врагов пусть по старому. Вокруг окружённого со всех сторон стенами факела не появляются.

Предложение Producer'а принято вместо «4 сторон»: одна тень-силуэт на предмет, сдвиг/наклон в вершинном шейдере по общему вектору солнца (плавно, почти бесплатно); у построек — объём (низ + верх, сдвинутый по солнцу → параллелограмм).

## Что сделать
1. **Солнце.** Вектор солнца от такта суток (с сервера): восход — тень длинная на запад, полдень — короткая на север, закат — длинная на восток; сумерки — бледнеет; ночь — солнечной тени нет. Числа (длина ×высота, азимут) — в таблице `DayTintView`/новой `SunTable`, помечены как предварительные. Деревья, кусты, валуны, персонажи, враги, постройки, кучи — все через один механизм; тень гор — тоже (длинная вечерняя).
2. **Закрытые комнаты.** Область, замкнутая стенами/дверями (сетка 0,5, тонкие стены 2.12; открытая дверь не размыкает комнату) — поиск заливкой, кэш по чанкам, пересчёт при правке стены/двери. Внутри комнаты солнечной тени нет; солнечная тень снаружи обрезается по стенам и в комнату не заходит.
3. **Тени от факелов/костров.** Видимость источника с учётом стен (луч/видимость на сетке 0,5, только для картинки): свет за стену не проходит. Каждый предмет отбрасывает тень от каждого из 2–3 сильнейших ближних источников, прочь от источника, темнота ∝ вкладу источника; несколько источников — несколько бледных теней. Тень за стену не попадает.
4. **Враги (ядро).** Освещённость для появления врагов — **по-старому** (`LightIndex` без учёта стен). Новое правило: в замкнутой стенами области, где есть факел/костёр, враги не появляются (комнаты из п. 2 — в ядре, детерминированно; без пола тоже). Тест ядра; правило в `work/modules/daylight.md` `[док]`.
5. Производительность: кадры/с на обзоре 64 днём и ночью с 10 факелами — не хуже −10 % (замер до/после в отчёте).
