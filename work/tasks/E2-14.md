# E2-14 — постройки сами восстанавливают прочность, 3 % в секунду

**Модуль-владелец:** `building` (+ `net`, `worldview`). **Ветка:** `task/E2-14`. **Источник:** ответ Автора 15.11, `BRIEF.md` п. 11f.

## Слова Автора (дословно)

«Давай повреждения сами лечатся по 3 % в секунду».

## Правила (допущения — в «Решения»)

- Повреждённая постройка восстанавливает **3 % максимальной прочности в секунду** (полная — примерно за 33 с), пока не станет целой.
- Восстановление начинается через **3 с после последнего урона** — та же задержка, что у починки молотом (`docs/05`, C-005). Пока по постройке бьют, она не лечится.
- Детерминизм: целые числа; 3 % в секунду при 30 тактах — накопитель в 1/1000 прочности (или шаг раз в N тактов), без дробей. Остаток не теряется.
- Починка молотом остаётся (быстрее и сразу); снос повреждённой постройки возвращает предмет целиком (решение 2.11) — теперь это согласовано: «повреждение временно».
- Сеть: прочность доходит до клиента так же, как сейчас при уроне и починке, но не каждый такт — изменения прочности одной постройки отправляются не чаще раза в секунду (или при достижении целой), чтобы не забивать канал при осаде. Если нужен новый формат — следующий номер протокола.
- Сохранение: прочность и время последнего урона уже/должны сохраняться; при загрузке восстановление продолжается.

## Шаги

1. Ядро: шаг восстановления в такте для повреждённых построек (список повреждённых, не обход всего мира), задержка после урона.
2. Сеть: редкая рассылка изменений прочности.
3. Клиент: полоска прочности при наведении растёт; трещины/затемнение повреждённой постройки (если уже есть) уходят.
4. Тесты: стена с 50 % через 3 с без урона начинает расти и через ~17 с целая; урон сбрасывает задержку; масса и предметы не меняются; детерминизм (два прогона — один хэш); сохранение и загрузка посреди восстановления; нагрузка: 500 повреждённых построек — шаг укладывается в бюджет такта.

## Готово, если

- А: тесты выше; ночные боты и `D08_3_1` зелёные (стены теперь лечатся между атаками — проверить, что приёмки 1.5–1.6 `docs/08` не стали ложно зелёными из-за восстановления; если враг пробивал стену раньше и не пробивает теперь — это ожидаемо, записать).
- Проверка (П) — принято.
