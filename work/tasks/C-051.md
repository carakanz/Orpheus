# C-051 — несколько щелчков по рецепту = количество, один щелчок в сумку — изготовить столько

> История с тем, что если я хочу сделать несколько слитков, мне нужно несколько раз нажать в разделе изготовление и потом 1 раз нажать в инвентаре — не сделана

## Сейчас (C-013/C-029)
Щелчок по рецепту выделяет его («в руку»), щелчок по ячейке сумки — изготовить 1 (Shift — 5, Ctrl — сколько влезет). Повторный щелчок по рецепту количество не наращивает.

## Что сделать
1. Каждый следующий щелчок ЛКМ по уже выбранному рецепту — **+1 к количеству** (ПКМ по рецепту — −1; колесо над рецептом — ±1, по желанию); у курсора/значка рецепта — число «×N».
2. Щелчок по ячейке сумки (или по земле для построек — тогда ставится 1, остальное в сумку? — решить и записать) — изготовить **N** сразу (если материалов на N нет — сколько хватает, остаток красным C-029); выбор снимается или остаётся с N=1 — записать.
3. Показ «останется» красным (C-029) — под N.
4. Сервер: одна заявка на N (как Shift/Ctrl сейчас), без N отдельных заявок; ответы/отказы.
5. Тесты (UI-логика чистым C# и сеть: N=3 слитка — материалы списаны на 3, в ячейке 3), снимок «×3».
