Убрать мёртвый код (`PredictedAt`, `TrySent`, буфер отправленных).
4. **net-smoke через имитатор связи** (`NetSimTransport` — RTT 100, разброс 20, потери 1 %), жёсткий порог: правок на чистом движении ≤ 2, расхождение ≤ 8 unit; сверка с позицией сервера, а не клиента с самим собой. Мутации проверки M1 (переигровка без неподтверждённых), M3 (гашение мгновенное), M4 (без тора), M5 (сверка с ack − 2) — каждая краснит тест или smoke.
