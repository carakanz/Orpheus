# P-005 — Big-бенч поиска пути: годность машины (аппаратный бюджет)

Дата: 17.11.2026 · Ветка: — (карточка заведена из P-003) · Статус: открыта, ждёт Claude Code/Автора (локальному исполнителю не поручать — «Решения» 17.11)

## Зачем

`D02_S9_2_Big_Bench1024_ThinHouses_1000Ticks40Searches` краснеет **соло, в тихом прогоне** на
8-ядерном dev-ПК (16 логических): 74,0 мкс на поиск × 40 поисков за такт = 2,96 мс = **99 % бюджета
3 мс за такт** (docs 07 2.4) → очередь растёт на ~1 поиск/такт → наибольшее ожидание 50 > 5 тактов.
Среднее за такт 2810 мкс ≤ 3000 — правило docs 02 9.2 выполнено; дефекта ядра нет. Эталон docs 09:
~60 мкс/поиск (80 % бюджета). Под 16 CPU-спиннерами мкс/поиск 106 — красные оба бенч-теста,
ожидание 116: часы CPU-времени нити (P-003) честно считают замедление самого поиска.

Пороги 3 мс / 5 тактов ослаблять нельзя (правило 4 `AGENTS.md`). Big по правилам гоняется на
сервере; на dev-ПК эти тесты — источник шума в `-All` (строка в `work/flaky.md`).

## Что сделать (решает Автор)

1. Выбрать режим: (а) бенчи-с-порогами только на сервере (отдельная приёмка), в `-All` — только
   корректность (число завершённых поисков, хэш), без временных порогов; (б) префикс категории
   (например `Big.Server`) и прогон по расписанию на сервере; (в) список эталонных машин
   (µs/поиск ≤ ~65) и запуск порогов только на них.
2. Калибровка-предупреждение (маленькая правка в тесте, пороги не трогает): перед прогоном
   планировщика печатать замер `RunDirect` (уже считается: мкс/поиск ср) и при ср > 65 мкс
   писать строку «машина не годится для бенча (docs 09): N мкс/поиск» — чтобы падение было
   объяснимо в логе без разбора.
3. Числа замера машины — в `work/codemap.md`/карточку после выбора режима.
4. Замечание П P-003 (`eca147f`): у `FreezeIsStall` снята верхняя граница числа простых —
   «шторм простых» (много замедленных тактов) теперь не ловится. Добавить событийный порог:
   простые с зазором ≥ ~100 мс (вне заморозки) считать не более N за прогон — так, чтобы
   шум планировщика (38 мс) не краснил, а деградация тика — краснила.
