# C-027 — мир: горы непрозрачные, растительность вместо троп, виды лесов, медь, глубокая вода

Модули: `worldgen`, `worldview`, `sim`. Ветка `task/C-027`, копия `.claude/worktrees/tc027`.

## Что сделать

1. **Гора не становится прозрачной** вокруг персонажа за ней (C-016 сделал круг полупрозрачности). Вместо этого — силуэт/контур персонажа поверх горы (как в играх с наклонной камерой), гора остаётся сплошной.
2. **Коричневые линии (тропы `Dirt`)** выглядят плохо — убрать полосы-тропы из генератора; вместо них пятна растительных «микробиомов» на лугах/у воды: цветы, подсолнухи, камыши у воды, высокая трава, папоротник в лесу. Декор без коллизий (или кусты по C-018 правилам), детерминированно по зерну.
3. **Леса разных видов** по типам деревьев: несколько лесных подтипов (например, дубрава, сосновый бор/кипарисы, берёзовая роща/оливы, тёмный ельник) — кластерами, со своим набором деревьев, подлеском и оттенком земли; генератор ставит тип по зоне (влажность/высота), вид — `worldview`.
4. **Медь не найдена Автором** за игру: проверить частоту и видимость залежей меди около старта (в радиусе ~150 тайлов от Очага гарантированно 2–3 выхода меди на поверхность, видимые и доступные медной кирке? — каменной кирке, по рецептам), отличимый вид медной руды на карте; тест генератора «медь в радиусе N от старта на всех зёрнах 1…30».
5. **Глубокая вода непроходима** (пока): генератор помечает глубину (отмель — у берега 1–2 тайла, глубина — дальше); по отмели — проходимо с замедлением (C-018), по глубокой — стена (и для врагов, и для пути); броды через реки — отмель. Вид глубины уже есть (тёмная вода) — совместить с правилом. Связность мира (тест v8) сохранить.
Генератор → v9, golden; старые миры не перестраиваются.
