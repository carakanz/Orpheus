## Шаги

1. `Orpheus.Server`: цикл такта 30 Гц (в обычном режиме — по часам, в режиме `--sim` — без часов, как можно быстрее); порядок такта задать явно (ввод → движение → правки мира пачками, «одна пачка на чанк за такт» — здесь, как требует backlog → события). Мир — `WorldModel` (0-005), сущности — список по номеру.
2. Ввод: структура кадра ввода (направление 8 + кнопки), журнал ввода в файл (`--record <путь>`), повтор (`--replay <путь>`).
3. Хэш состояния (`--hash`): канонический вид по 11.5 — сущности по номеру со всеми полями, тайлы изменённых чанков, флаги мира; SHA-256 или свой 64-битный (обоснуй); печать на каждом 300-м такте.
4. Боты без сети как источник ввода в симуляции: `idle`, `wander` (детерминированный, от зерна).
5. Аргументы по 11.2: `--world <папка> --create --seed N --size 1024|4096 --sim --bots 8:wander --ticks N --hash --record/--replay`. Мир при `--create` — пока плоский (генератор делает 0-007; оставь точку подключения `IWorldGenerator`).
6. Логи — JSON-строки по 11.6 (минимум: время, такт, уровень, категория, сообщение).
7. Хвост из backlog: `tools\ci.cmd` больше не оставляет `log.txt`.
8. Тесты `D00_Sim_*`: приёмка 0.3 — 8 ботов `wander`, 54 000 тактов на 1024²: не медленнее ×10 реального времени (замер в тест-отчёт; сам тест можно пометить `Category=Big`), повтор журнала даёт тот же хэш на каждом 300-м такте; мутация (например, порядок ботов) меняет хэш.

## Как устроено (для проверяющего)

- `src/Orpheus.Core/Sim/Simulation.cs` — такт. Порядок: 1) ввод (кадры до такта становятся текущими, без нового кадра — держится прежний); 2) движение сущностей по номеру по миру начала такта; 3) правки: запросы такта сортируются устойчиво по чанку (Y, X), внутри — по приходу; **на чанк — один `WorldModel.ApplyEdits`**, ревизия +1; 4) события (исходы правок, новые ревизии) — в буфер такта. Все буферы — заранее; переполнение очереди правок — отказ (`RequestEdit` → false).
- Проходимость для движения (`Simulation.IsBlocked`) — из таблиц `FloorId`/`ObjectId` (`05` 1.3): непроходимый пол (лава), непроходимый объект, «часть» — по якорю, дверь — по флагу записи.
- `StateHash` — канонический вид 11.5: заголовок (такт, зерно, форма, версия генератора); сущности по номеру со всеми полями; изменённые после генерации чанки (координата, ревизия, слои 3072 байта, записи построек по индексу); флаги мира — число 0 (флагов ещё нет). **Свой 64-битный, не SHA-256**: хэш считается в такте сервера раз в 10 с, а 11.6 запрещает выделения в такте; `Hasher64` (шаг `Mix(h ^ слово) + Step` на SplitMix64) не выделяет и не зависит от криптобиблиотеки платформы; цель — поймать расхождение, а не подделку. SHA-256 остаётся у файлов (3.4, 6.3).
- Журнал ввода (`InputJournal.cs`): заголовок (мир, такт начала, сущности с позициями) + записи «изменения ввода перед тактом N», «точка сверки после такта N» (общий хэш, хэш мира, хэши сущностей), «конец». Пишутся только изменения ввода: 54 000 тактов × 8 ботов = 118 КБ. Повтор сверяет точки и называет такт и сущность (или «мир»), код выхода 1.
- Боты (`src/Orpheus.Core/Bots/SimBot.cs`): `idle`; `wander` — 8 направлений или стойка (1 из 9), выдержка 0,5–3 с, генератор от SplitMix64(номер бота, система, зерно).
- Сервер: `ServerOptions` (ключи 11.2 + `--logs`, `--log кат=уровень`, `--port` — принят, сети нет), `ServerRun` (мир: `--create` → генератор → `world.base` в папке мира, без `--create` — загрузка `world.base`; без `--world` — мир только в памяти), `TickClock` (отставание до 3 тактов догоняется, больше — бросается с предупреждением «перегрузка»), `JsonLog` (`<мир>/logs/server-ГГГГ-ММ-ДД.jsonl` + консоль; поля time, tick, level, cat, msg, data).
- Пример: `dotnet run -c Release --project src/Orpheus.Server -- --world C:\tmp\w2 --create --seed 42 --size 1024 --sim --bots 8:wander --ticks 54000 --hash --record C:\tmp\inputs.bin`, затем `... -- --world C:\tmp\w2 --sim --replay C:\tmp\inputs.bin --hash`.

## Отклонения и вопросы

- **`IWorldGenerator` — в `Orpheus.Core.World`** (а не в `Orpheus.WorldGen`): сервер и тесты подключают генератор через ядро, `StubGenerator` из 0-007 реализует этот интерфейс; подставляется в `ServerRun.Generator`. Если 0-007 заведёт свой интерфейс — при слиянии оставить один (этот).
- **`World/` тронут** (0-005, поток Я): `BuildMapPool` + конструктор `Chunk(BuildMapPool?)` + `WorldModel.BuildMaps` — хвост backlog [такт сервера]. Пул отдаёт словарь на 128 записей *(прикидка)*; пополнение — `Simulation.RefillPools()` между тактами.
- `tools\ci.cmd` — комментарии по-английски: файл должен быть ASCII (кириллица под cmd и давала `log.txt`).
- Тест-проект ссылается на `Orpheus.Server` (exe): тесты `D00_Sim_*` гоняют `ServerRun.Run` в процессе.
- Сервер вне такта выделяет ≈ 3,6 байта/такт в `--sim --hash` — строки лога хэша раз в 300 тактов и список хэшей для отчёта; в самом такте (`Step` + хэш) — 0 (тест).
