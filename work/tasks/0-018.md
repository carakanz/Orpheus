**Поток:** Я (служебное, сеть). **Ветка:** `task/0-018` (рабочая копия `.claude/worktrees/t018`). **Веха:** 0. Повод — слово Автора 07.11: из каждой рабочей копии агентов Windows спрашивает доступ к сети.

**Цель:** правило брандмауэра Windows привязано к пути программы, а у каждой рабочей копии свои `testhost.exe`, `OrpheusServer.exe`, `Orpheus.Bots.exe`, `Orpheus.exe` — отсюда окно на каждую копию. **Ссылки:** `src/Orpheus.Net/Transport/LiteNetTransport.cs` (`Listen`, `Connect`), `src/Orpheus.Server/ServerOptions.cs`, `ServerRun.cs`; `docs/07_multiplayer_tech.md` 11.2 (ключи сервера) — ключ `--public` в документе ещё нет → `[док]` в `work/backlog.md`.

## Шаги

1. `LiteNetTransport.Listen(port, maxPeers, loopbackOnly)`; `Connect` к `localhost`/127.x/::1 — `Start(Loopback, IPv6Loopback, 0)`; `IsLoopbackHost`.
2. Сервер: по умолчанию `LoopbackOnly = true`; `--public` — все адреса (игроки с других машин).
3. Тест: сервер по умолчанию и клиент к 127.0.0.1 — все их UDP-сокеты на петле (`IPGlobalProperties.GetActiveUdpListeners`); разбор `--public`.
