## План
1. Поле `Action` (byte) в `SnapshotEntity`: 0 — покой; инструмент 2 бита (1 — кирка, 2 — лук),
   прогресс 6 бит (кирка: кадр замаха из окна взмаха; лук: сила `PowerQ8>>2`… точную раскладку
   зафиксировать в коде и тестах голденами). Только для персонажей; враги — 0.
2. Сервер: заполнение из bow-фазы (`Bow.Phase != 0` → лук, прогресс `ShotDraw`/`FullDrawFrames`)
   и окна взмаха кирки (копание игрока: прогресс от начала взмаха); дельта-бит 64 в
   `NetServer.Snapshots.cs` (сравнение + `TryAdd`/`TryAddUpdated`/`TryAddAdded`).
3. Клиент: `NetAnimation.Remote` — по `Action`: замах кирки (поза как у меча, инструмент — кирка),
   натяжение лука (`DrawPower` из прогресса, «внатяг» пока фаза активна, конец — выстрел-отдача).
4. Голден-байты снимка с новым полем; тесты: дельта приходит при смене фазы и только тогда;
   копка чужого видна в снимке (rig: копает A, B видит `Action` A); лук чужого (натяжение →
   полный → 0); свои анимации не меняются.
5. Снимки экрана (`tools/shots.ps1`, скрытый стол): два клиента — один копает скалу, второй

## Решения
- Раскладка `Action` (8 бит): инструмент — младшие 2 бита (0 покой, 1 кирка, 2 лук),
  прогресс — 6 бит (`ActionProgressShift=2`, маска `0x3F`); `EncodeAction` клампит
  прогресс 0…63. Дельта-бит `DeltaFields.Action = 64`, `MaskBits` 6→7, `ActionBits=8`.
- Кирка: прогресс = `ceil(DigProgress / 16)` — квант `SnapshotLayout.ActionDigQuantum = 16`
  (~0,27 с на шаг; вынесен в layout — клиент считает длину замаха чужого по тому же кванту).
  Дельта — раз в окно, не каждый такт. Взмах 24 кадра → шаги 1, 2.
- Лук: только `Bow.Phase == PhaseDraw`, прогресс = `PowerQ8(Frames) >> 2` (0…63; Q8 256 →
  64 → клампинг 63). На полном натяжении выстрел в тот же кадр — снимок успевает увидеть
  ~58 (проверка `InRange 56…63`). Отход (`PhaseRecover`) — 0: отдачу клиент рисует по
  сообщению снаряда (E3-2). Зажатая ЛКМ — непрерывная стрельба (C-031): тест отпускает
  на 36-м кадре, иначе сегмент натяжения возобновляется.
- Клиент `NetAnimation.RemoteAction`: кирка — замах по шагам (окно = шаг × квант,
  `ActionSec`/`ActionFrames` для `BeatPhase`); лук — `DrawPower = step/63`, `DrawSec` из
  обратного `PowerQ8`; ось — взгляд (`FacingRight`, прицела чужого в снимке нет). Словарь
  чистится в `ForgetGoneMelee` (счётчик `RemoteActionTracked`).
- Протокол 36 → **37** (9 тестовых assert'ов подняты). Сейв 16 не трогается.
  Голдены `D07_S2_10_GoldenBytes_AllMessages` обновлены (снимок 48 байт, дельта 50) +
  assert'ы Action (round-trip, дельта-бит, added).
