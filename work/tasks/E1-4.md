# E1-4 — земля мешем без клетки, переходы, вода (план: шаги 1.4, 1.5)

**Модуль:** `worldview`. **Ветка:** `task/E1-4` (рабочая копия `.claude/worktrees/te14`). **План:** `work/PLAN.md`, этап 1.

**Цель:** земля без видимой клетки (текстуры 4 × 4 тайла по координатам мира), мягкие неровные границы между видами земли, вода в два тона с линией берега и движением; правка тайла видна в тот же кадр; ≥ 60 кадров/с на обзоре 96.

## Что сделано

- **Меш земли на чанк** (`GroundMesh.cs`): «двойная сетка» — 32 × 32 квадрата между центрами тайлов (чанк закрывает [−0,5; 31,5] тайла). В вершинах квадрата — номера слоёв четырёх тайлов вокруг, место внутри квадрата и координата мира в тайлах (по модулю 256: числа малые, рисунок не зависит от «плавающего начала» и сходится на шве тора). Тайлы за краем чанка берутся из соседних чанков мира (3 тайла: 1 для квадратов + 2 для «отмель/глубина»).
- **Шейдер `Orpheus/Ground`** (`client/Assets/Shaders/Ground.shader`, URP 2D, проходы `Universal2D` и `UniversalForward`): `Texture2DArray` слоёв; у слоя каждого угла — билинейный вес + шум своего слоя + прибавка по приоритету, рисуется слой с наибольшей суммой (жёсткий край в 1 px, излом ±0,35 тайла), по краю верхнего слоя — тёмная кромка. Против повтора 4 × 4: изгиб картинки крупным шумом и смешивание с копией вдвое крупнее по пятнам шума, лёгкая смена тона.
- **Вода (1.5):** слои «глубина» и «отмель»; отмель — вода ближе ~2 тайлов к суше (решает сборщик меша), граница между ними мягкая; на воде у суши — светлая линия берега, ширина «дышит»; картинка воды колышется и медленно плывёт (`_Time`).
- **Таблица «FloorId → вид»** (`GroundTable.cs`): массив строк (пол, слой, как рисовать), 32 места с запасом; слои по приоритету: глубина < отмель < песок < земля < сухая трава < трава < лес < камень. `DryGrass` в ядре нет — строка на номер 12 (первый свободный) с комментарием.
- **Построенные полы** (`StoneFloor`, `WoodFloor`, `Platform`) — как раньше, плиткой Tilemap поверх меша (каменная плита-заглушка); Tilemap пола природные полы больше не рисует.
- **Импорт картинок** (`Editor/GroundImport.cs`): `[TEMP_]ground_*.png`, `[TEMP_]water_*.png` из `Assets/Art` — всегда обычная текстура, повтор, mip, трилинейный фильтр, без сжатия, читаемая; `Assets/Resources/GroundSet.asset` (список картинок + шейдер) пересобирается при импорте и перед каждой сборкой — шейдер и картинки попадают в сборку сами. Клиент собирает массив текстур при запуске (`GroundAtlas.cs`): нет картинки слоя — ровный цвет и предупреждение, другой размер — пересчёт.
- **`--paint-demo`** (`PaintDemo.cs`): озеро неправильной формы с песчаным берегом, лужа, пятна земли/сухой травы/подстилки/камня, тропинка в тайл, две площадки построенного пола; в 70 тайлах к востоку — стык шести видов земли вокруг пруда. Только офлайн, только для снимков.
- **Стенд:** поле `args` у сцены в `tools/shots.json`; сцены 08–12 с `--paint-demo`. `tools/run_tilebench.ps1 -Render [-Gen v1]` — замер с отрисовкой (`--bench-render`: камера каждый кадр рисует в текстуру 1920 × 1080 и ждёт видеокарту), запуск через `tools\run_hidden.ps1`.

## Решения

- **Переходы — шейдером по двойной сетке, а не набором из 15 плиток перехода:** не нужны картинки переходов на каждую пару видов, граница получается рваной по шуму и одинаковой для любых новых картинок с Мака.
- **Номер слоя = приоритет.** Шейдеру не нужны таблицы: «вода» — слои с номером < 2, «кто сверху» — больший номер.
- **Отмель/глубину решает клиент** по расстоянию до суши (вода ближе √5 тайла к не-воде — отмель), а не генератор: в `FloorId` одна вода.
- **`FloorId.Stone` → каменистая земля** (`ground_rocky`) мешем; серая плита `TEMP_tile_stone` осталась только у построенных полов. `Snow`, `Lava`, `Empty` своих картинок не имеют — см. комментарии в таблице.
- **Проверки smoke и tile-bench** сверяли плитку Tilemap пола с ядром; теперь плитка есть только у построенных полов, а для земли добавлена сверка `WorldView.GroundShows` (копия полов узла, по которой собран меш). Пороги не менялись. `[док]`
- **Координата мира в меше — по модулю 256 тайлов:** периоды картинок (4, 8) и шума (16, 32, 64) её делят; размер мира должен быть кратен 256 (сейчас 1024), иначе на шве тора будет виден стык крупного шума.
- **`.meta` прочих картинок набора E1-9** (деревья, валуны, обрывы) Unity создал при импорте, но в коммит не взяты — их импорт настроят шаги 1.6–1.7.

## Что ещё плохо (честно)

- Картинки земли — скриптовые «пятна»; на обзоре 96 в лугу ещё угадываются ряды пятен и области «мелко/крупно» от смешивания против повтора. С картинками Мака должно стать лучше; параметры — `_Mix`, `_Warp` в шейдере.
- Тропинка шириной в один тайл по диагонали рвётся на отдельные пятна (у двойной сетки диагональные соседи связаны слабо) — генератору лучше делать тропы от 2 тайлов.
- Граница глубина/отмель мягкая (0,15 тайла) — выбивается из «плоского» стиля; линия берега тонкая на обзоре 96 (1 px).
- Построенный пол — старая серая плита с пурпурными уголками, клетка на ней видна.
- В воду персонаж заходит (вода проходима в ядре) — это шаг 1.2/правила, не вид.
