# E2-9 — окно «инвентарь + изготовление» как в Terraria, рецепты по разделам и подразделам

**Модуль-владелец:** `ui` (+ `items`). **Ветка:** `task/E2-9`. **Источник:** приёмка этапа 2 Автором 15.11, `BRIEF.md` п. 11e (1).

## Слова Автора (дословно)

«Нужно меню крафта и строительства примерно как в Террарии. Инвентарь с предметами и окно крафта. Я бы только вместо бесконечного списка, как в Террарии, сделал бы подразделами. Здания — там подразделы по материалам. Мебель — там по типу, оружие, броня».

## Цель

Одно окно (Tab): слева сумка (как сейчас), справа изготовление. Рецепты не бесконечным списком, а разделами и подразделами. Окно изготовления — единое место и для крафта предметов, и для «строительства»: стены, полы, двери и мебель — это предметы, которые сначала делаются здесь, а потом ставятся из инвентаря (E2-11).

## Что видит и нажимает игрок

- **Tab** — открывает сумку и изготовление вместе; **Esc/Tab** — закрыть. Клавиша C — открывает то же окно сразу на изготовлении (оставить для привычки).
- **Разделы** (вкладки сверху): Здания · Мебель · Инструменты · Оружие · Броня · Материалы · Еда. Набор разделов — данными (таблица в ядре или клиенте, без `if`), его можно менять без кода.
- **Подразделы** (вторая строка или столбец слева):
  - Здания — **по материалам**: Дерево · Камень · Медь (дальше по мере появления материалов).
  - Мебель — **по типу**: Станки (верстак, костёр…) · Хранение (сундук) · Сон (кровать) · Свет (факел…) · прочее.
  - Оружие — по типу (мечи, луки, стрелы); Броня — по частям или по ярусу; Инструменты — по типу; Материалы, Еда — без подразделов или по станку.
- **Сетка рецептов** подраздела значками (как в Terraria): доступное ярко, недоступное приглушено; на значке — сколько можно сделать. Наведение — подсказка: название, ингредиенты «есть / нужно», нужный станок.
- **Карточка выбранного** — как в окне крафта E2-4 (результат, ингредиенты, время, «Сделать 1 / 5 / всё»), очередь изготовления ниже.
- **«Есть»** считается по сумке **и сундукам поблизости** (E2-10). Пока E2-10 не слито — только по сумке.
- **Фильтр «только доступные»** (галочка) — показывать только то, что можно сделать сейчас.

## Решения (приняты без Автора)

| № | Решение | Почему |
|---|---|---|
| 1 | Таблица полок — **в `src/Orpheus.Net/Session/CraftShelf.cs`** (рядом с `CraftDesk`, новый файл), а не в `RecipeTable` ядра | ядро и `CraftDesk` правит E2-10 параллельно; раскладка — данные показа, правил игры в ней нет; тесты видят её, клиент — тоже (DLL) |
| 2 | Раскладка — **по ключу предмета-результата** (`ItemDef.Key`), не по номеру рецепта | так просила карточка; два рецепта одного предмета попадут в одну полку |
| 3 | `CraftDesk` **не правился**: число и фильтр — `CraftShelf.Badge` / `Shown` над `CraftLine` | меньше конфликтов с E2-10; «есть» из сундуков придёт через `LineOf` само |
| 4 | Число на значке — **штук результата** (изготовлений × выход: стрелы при материалах на 5 изготовлений — 50), 1 тоже пишется; станка нет рядом — число видно, значок приглушён | рядом с сумкой, где стрел 250, «5» читалось бы как 5 стрел; приглушённое число говорит «материалы есть, нужен станок» |
| 5 | Подразделы: Здания — Дерево / Камень / Медь (пусто до E2-11), Мебель — Станки / Хранение / Сон / Свет / Прочее (факел — в «Свет»), Инструменты — Кирки / Топоры / Молоты, Оружие — Мечи / Луки / Стрелы, Броня — Шлемы / Доспехи / Поножи (пусто), Материалы и Еда — без подразделов | слова Автора + карточка; пустые подразделы заведены заранее для E2-11 и брони |
| 6 | Tab и C открывают **одно и то же окно** (сумка + изготовление); «сразу на изготовлении» = раздел и подраздел, открытые в прошлый раз, клавиши окна (PgUp / Enter…) всегда идут в изготовление. Вкладок станков больше нет: станок — в карточке и подсказке («Нужен верстак рядом») | одно окно, как в Terraria; станок — свойство рецепта, не раздел |
| 7 | Окна остались двумя наследниками `UiWindow` (сумка и изготовление), открываются и закрываются вместе, верхние края вровень | сумка нужна и рядом с сундуком (E2-5); одна точка попадания на окно не ломается |
| 8 | Клавиши: Home / End — раздел, **Shift+Home / End — подраздел**, PgUp / PgDn — рецепт, **Ins — «Только доступные»**, колесо над сеткой — прокрутка | буквы рядом с WASD и F заняты игрой |
| 9 | Сетка 8 × 6 = 48 значков; в срезе подраздел ≤ 3 рецептов, так что полоса прокрутки сейчас не видна (появится сама, когда рецептов > 48) | прокрутка проверена рассуждением по коду (`MaxScroll`, `Pick`, `ThumbRect`), не снимком |
| 10 | Сцена `inv` начинается не с «Здания → Дерево» (до E2-11 там пусто), а с «Инструменты → Кирки» с очередью и подсказкой; пустые «Здания → Дерево» — отдельная сцена `inv-buildings` | на пустой сетке нечего проверять глазами; после E2-11 сцену `inv` переключить на «Здания» (одна строка `InvSteps`) |
| 12 | Сцена E2-10 `craft-chest` переведена на шаги нового окна (Инструменты → Кирки → медная кирка); подсказка значка считает «есть» тем же `CraftDesk.Have(…, stock)`, что карточка | при слиянии E2-10 старые вкладки и строки исчезли |
| 13 | Tab теперь открывает и изготовление: сцена `E2-2_bag` после пересъёмки покажет оба окна | одно окно по слову Автора |
| 11 | Прежние сцены `craft`, `craft+bag` идут скриптом `inv` (вкладок и строк больше нет); их снимки `E2-4_*` после пересъёмки будут показывать новое окно | старые части окна удалены |
