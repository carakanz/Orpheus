## Шаги

1. **Все действия — `InputAction` в `GameBoot.CreateInput`**: движение, прицел (мышь), основное (ЛКМ, удержание), вторичное (ПКМ, удержание), уворот (Shift / X / геймпад B — как в 0-034), взаимодействие (F), быстрый факел (T), ячейки 1–8, колесо, B — молот / прежний предмет, зум (Ctrl + колесо, [ ]), F2, Esc.
2. **Буфер нажатий** (`02` 1.2) чистым классом без Unity, в `client/Assets/Scripts/Input/` или в ядре клиента: нажатие атаки, уворота, взаимодействия за ≤ 0,2 с до конца действия выполняется по его окончании; ожидание направления уворота 0,1 с (0-034) — сюда же. Юнит-тесты в `tests/`.
3. **ЛКМ по предмету в руках:** меч — бит атаки; лук — удержание (натяжение); кирка / топор — копание тайла под курсором (как сейчас); молот — постановка (палитра 1-020). С молотом Q / E / Z / C — клавиши палитры, а не способностей (`05` 1.3).
4. **T — факел без молота** под курсор по правилам постановки (запрос 1-011).
5. **Подсказки на экране** (`02` 1.6 п. 1): строка с клавишами вехи 1 — заглушка текстом.
