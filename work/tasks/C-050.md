# C-050 — броня в меню изготовления и в вики — по сетам, а не по типам

Модули: `ui`, `items`. Ветка `task/C-050`, копия `.claude/worktrees/tc050`. Слово Автора 21.11 (приёмка), дословно:
> Броню лучше по сетам делить а не по типам

## Что сделать
1. В окне изготовления (разделы C-008/C-013) броня группируется по наборам: «Медный набор» — шлем, нагрудник, поножи рядом; будущие наборы (железный и т.п.) — своими группами. Не «все шлемы / все нагрудники».
2. В данных предметов (`items`) — поле «набор» у брони; сортировка внутри раздела по набору, затем по слоту (голова → тело → ноги).
3. Если у набора будет бонус за полный комплект — НЕ делать без слова Автора, только вопрос в карточку.
4. Вики (`wiki/src/items.json` / `merge.py`) — та же группировка по наборам.
5. Тест порядка (чистый C#), снимок окна изготовления.
