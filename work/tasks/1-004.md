# 1-004 — меч игрока: серия, сектор и линия удара, отбрасывание

**Поток:** Я (бой в ядре, предсказание замаха). **Ветка:** `task/1-004` (рабочая копия `.claude/worktrees/t1004`). **Веха:** 1 «Прототип» (`08` 3.1, недели 16–17).

**Зависимости:** после слияния **1-001** (урон) и **1-002** (предмет в руках, прицел); желательно после **1-003** (флаг рывка для отмены). **Параллельно можно:** 1-007 (враги — разные файлы; общий `Simulation` — сливать по очереди), 1-010, 1-011, 1-012, 1-014. **Ждут эту карточку:** 1-005 (отмотка), 1-006 (общий автомат действия персонажа), 1-019, 1-023.

**Цель:** игрок бьёт мечом: три удара серией, сектор перед собой по прицелу, через забор можно, через стену нельзя; разбойник падает за 4 удара. Удар считает сервер по текущим позициям; отмотка на время картинки — следующая карточка 1-005.

**Ссылки:** `docs/02_combat.md` 3.1 (фазы, сектор, линия удара), 3.2 (строка «Меч»: 0,15 / 0,15 / 0,35 с, 120°, серия ×1,0 / ×1,0 / ×1,3, отбрасывание 1,0, третий ×2, бег 70 %, правила серии), 3.4 (края: шов, забор, стена, PvE не задевает своих, оружие не ломает постройки), 3.7 п. 1–3, 1.2 (буфер нажатий 0,2 с, удержание ЛКМ — повтор, поворот к прицелу), 1.6 п. 3, 2.2 (строка «Отмена действий»), 2.7 п. 3; `BRIEF.md` п. 11b (досягаемость = персонаж + оружие). Код: `src/Orpheus.Core/Combat/MeleeSector.cs`, `Reach.cs`, `src/Orpheus.Core/Movement/`.

## Шаги

1. **Автомат действия персонажа** (общий код сервера и предсказания): покой → замах 9 кадров → удар 9 → отход 21 (60 Гц); серия 3 удара; после третьего отход ×1,5 (0,52 с); пауза > 0,8 с после отхода — серия сначала; буфер — нажатие за ≤ 0,2 с до конца отхода продолжает серию; удержание ЛКМ — повтор. Поворот к прицелу мгновенный на время замаха и удара. Бег 70 % во время удара.
2. **Сектор удара** от центра персонажа: радиус — `Reach` меча (см. вопрос), дуга 120°, ось по прицелу; одна цель — одно попадание за удар; координаты по тору. **Линия удара:** отрезок центр—центр не пересекает стену, скалу, дерево, закрытую дверь; забор не прерывает.
3. **Попадание** в фазе «удар» → урон через 1-001 (база 10 × множитель серии, см. вопрос), отбрасывание 1 т (третий — 2 т) ÷ масса, прерывание по 6.6. В PvE игроков не задевает; постройкам 0 урона.
4. **Отмена уворотом** (флаг из 1-003): из замаха — удар пропал, из отхода — засчитан.
5. **Сеть:** кнопка «основное действие» в кадре ввода (бит); клиент проигрывает замах сразу в предсказании; результат — событие урона от сервера (1-001). Чужим — фаза действия в снимке (для анимации 1-023). Протокол +1.
6. **Unity минимально:** ЛКМ с мечом в руках — удар (полноценное управление — 1-018), сектор на земле — переиспользовать `SectorView` из K-001.
