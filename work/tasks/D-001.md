# D-001 — кандидаты в мобы из бестиария (Мак-Qwen размечает, картинки — Мак-ComfyUI)

Модули: дизайн (вики `wiki/`), `art`. Ветка `task/D-001`, копия `.claude/worktrees/td001`. Слово Автора 16.11, дословно:
> Я ещё предлагал взять https://new.ttg.club/bestiary и оттуда взять монстров (которые не являются лицензионными типа иллитида и совомедведя). Те же драконы например или гигантские черепахи. С этим думаю отлично справится модель с мака — она сможет подготовить список и проставить теги по критериям + описание + картинка. Дальше уже ты пропишешь игровые механики этих мобов.

## Что сделать
1. **Список.** Получить перечень существ бестиария (имя рус/англ, тип, размер, ПО/CR, среда обитания, ссылка) — бережно: официальный API/JSON сайта, если есть, иначе страницы списка; пауза ≥1 с между запросами, без обхода защит; кэш в `work/design/bestiary/raw/` (не в git, если больше 5 МБ). Описания с сайта **не копировать** в наши файлы — только поля-факты (имя, тип, размер, CR, среда).
2. **Фильтр прав.** Убрать фирменных монстров D&D (product identity WotC): бехолдер, иллитид/свежеватель разума, совомедведь, смещающий зверь, гит (гитьянки/гитзерай), кво-тоа, юань-ти, слаад, умбер-хульк, ракшас-? (сверить), карраш, ксорн и т.п. Правило отбора: оставлять существ из SRD 5.1 (CC-BY-4.0) и существ общей мифологии/фольклора/природы (драконы, черепахи-гиганты, гарпии, грифоны, кракен, гидра, тролли, вурдалаки, звери); всё сомнительное — в отдельный список «спорно» с причиной. Список PI и правило записать в карточку.
3. **Разметка на Мак-Qwen** (192.168.88.252:8080, OpenAI-совместимый, модель `qwen3.8-27b`, ключ из переменной окружения `MAC_AI_KEY`, не печатать; Мак сейчас на `llm`). Для каждого оставшегося существа — JSON: `biomes` (из 20 биомов вики `wiki/catalog.json`), `act` (I/II/III), `tier` (1–3 / элита / босс по CR), `archetype` (архетипы вики + новые), `role` (стая/засада/танк/стрелок/призыватель/летун/роющий/…), `night_only`, `size_tiles`, **своё короткое описание по-русски** (2–3 предложения, придуманные заново, не пересказ текста D&D), `image_prompt` (англ., стиль Б, вид сверху 3/4, один персонаж на нейтральном фоне). Батчами по 10–20, проверять JSON, повторять сбои. Ответы и промпты — в `work/design/bestiary/tagged.json`.
4. **Вики.** Новый раздел «Кандидаты из бестиария» (метка «кандидат», фильтры по биому/акту/тиру/архетипу) с отметками «принято/правка/убрать» и комментарием, как у остальных страниц; данные — через `wiki/src/*.json` + `merge.py` (согласовать с сессией вики `abilities-enemies`: она правит `wiki/` — делать в своей ветке, сливать будет Producer).
5. **Картинки** — после разметки, отдельным ночным заходом ComfyUI (Мак на `comfy`, Z-Image base): только для кандидатов с отметкой Автора «принято» или топ-40 по разнообразию, если Автор не успел отметить. Мак в конце — обратно на `llm`.

## Готово, когда

## Проверка (П)
(Producer + выборочно 20 описаний на «не пересказ»)

## Решения (исполнитель, 16.11)
- **Источник данных.** Страница `new.ttg.club/bestiary` сама берёт данные из `/api/v2/bestiary/search` (страницы по 200, `source=MM,…`), фильтры — `/api/v2/bestiary/filters`, карточка — `/api/v2/bestiary/{url}`. Скачано: 4 страницы списка, список SRD 5.2, 31 список по местам обитания и 395 карточек только отобранных (ради размера); пауза 1,2 с, всего ≈ 440 запросов. Кэш — `work/design/bestiary/raw/` (в git нет: там тексты сайта). У сайта `robots.txt` = `Disallow: /` (бета-зеркало, «indexing disabled») — обход разовый, по слову Автора, без повторов.
- **Что взято с сайта:** только имя рус/англ, тип, размер, CR, среда, ссылка (`candidates.json`). Описания и промпты пишет Qwen заново.
- **Семейства.** Драконы одного цвета (вирмлинг → древний) сведены в одного кандидата с вариантами и диапазоном CR: 395 существ → 365 кандидатов.
- **CC-BY-4.0.** Для существ SRD 5.2 нужна строка атрибуции в титрах («Часть материалов — System Reference Document 5.2 © Wizards of the Coast LLC, CC-BY-4.0»). Названия меняем на свои при переносе в игру.
- **Картинки (шаг 5)** не делались: в `tagged.json` у каждого есть `image_subject` (предмет) и `image_prompt` (= стиль Б + предмет + камера из `art/style/STYLE.md`).

## Фильтр прав (правило и списки)
**Правило.** Берём только Monster Manual 2024. Оставляем: (1) существ SRD 5.2 (CC-BY-4.0, флаг сайта «Версия SRD»), (2) существ общей мифологии, фольклора и природы (звери, драконы, гиганты, нежить, грифоны, гидра, кракен…). Убираем: фирменных существ D&D (product identity WotC, в SRD их нет, узнаются как бренд), совомедведя (по слову Автора, хотя он есть в SRD). Вне выборки: книги сеттингов (Эберрон, Забытые королевства, Равенлофт и др.), именные персонажи, сторонние и UA-источники; из них взяты только общефольклорные — цзянши, стригой, дуллахан, лу-гару, лебединая дева, гигантская муха, полярный змей. Формы заклинаний и спутники (духи PHB, стальной защитник и т. п.) — не противники.

**Убрано как PI (66 записей сайта):** бехолдер и родня (бехолдер, тиран смерти, наблюдатель, зомби-бехолдер, газовая спора); иллитид (свежеватель разума, арканист, вампир-иллитид, пожиратель интеллекта); гит (гитьянки, гитзерай — 6); кво-тоа (4); слаады (6); умбер-хульк; юань-ти (5); смещающий зверь; ползающий падальщик; совомедведь и первобытный совомедведь; модроны (5); нотик; грелл; микониды (3); квагготы (2); крючкастый ужас; три-крины (2); юголоты (4); йоклол; флампф; гноллы Йеногу (2); шлемоносный ужас; галеб дур; пылающий череп; кенку; ааракокры (2); заражённое дерево Гультиаса; сгусток уничтожения.
- Сверено с карточкой: **ракшас** — есть в SRD 5.1/5.2 и в индийской мифологии → оставлен. **Ксорн** — в SRD 5.2, но назван в карточке среди PI → в «спорно». **«Карраш»** в бестиарии не найден (возможно, имелся в виду карраш из Эберрона — книги сеттингов вне выборки целиком).

**Спорно (53 записи, в вики не включены, решает Автор):** исчадия космологии D&D вне SRD (личинки, мэйны, шипастый/бородатый/колючий дьяволы, барлгура, хасма, гористро, теневой демон, камбион, рои лемуров/дретчей/личинок — 14); растения-заразы (4); ползающая рука (2); буллиуги (2); троглодит; пронзатель; шакал-оборотень; фейский дракон (2); огриллон; эмпирей (2); водная странность; костяная нага; теневой дракон (2); драколич; демилич; рыцарь смерти (2); новые варианты 2024 от SRD-существ (психическая серая слизь, древний грик, некрохалк из фиолетового гриба); новые существа MM 2024 вне SRD (повелитель зверей, архикарга, стихийный катаклизм, колосс); ксорн; мифы Лавкрафта (7: Ктулху, шоггот, ми-го и др.).
