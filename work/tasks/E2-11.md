# E2-11 — постройки — это предметы: делаются в окне изготовления и ставятся из инвентаря

**Модуль-владелец:** `building` (+ `items`, `ui`, `net`, `save`, бот `build_room`). **Ветка:** `task/E2-11`. **Источник:** приёмка этапа 2 Автором 15.11, `BRIEF.md` п. 11e (3).

## Слова Автора (дословно)

«Для строительства стены нужно взять стену из инвентаря и нажать, куда».

## Цель

Как в Terraria: стена, пол, дверь, забор, факел, верстак, сундук, кровать — предметы. Их делают в окне изготовления (раздел «Здания» / «Мебель», E2-9) из материалов, кладут в панель, берут в руку и ставят щелчком. Лента построек молота (E2-5) уходит.

## Правила (допущения — в «Решения»)

- Каждая строка `BuildDefs` получает предмет-постройку в `ItemTable` (стопка 99 для стен/полов/заборов/факелов, 1–10 для мебели — по `docs/06`) и рецепт в `RecipeTable`: прежняя цена постановки становится ценой рецепта (одна постановка = один предмет; если в `docs/05/06` у стен выход «4 из 1 бревна» — брать из документа).
- В руке предмет-постройка → призрак под курсором (как в E2-5: та же проверка ядра `EditRules`, зелёный/красный с причиной), ЛКМ — поставить, зажатая ЛКМ — подряд; предмет снимается из стопки в руке. Нет предмета — постройки нет.
- **Молот** — только снос (ПКМ или ЛКМ по постройке) и починка. Снос возвращает **предмет-постройку** (стену), а не материалы (как в Terraria); разрушенная врагами постройка даёт обломки по `docs/05` (как сейчас).
- Сохранение: старые миры — постройки на месте; сумка старого формата читается.

## Шаги

1. Ядро: предметы-постройки, рецепты, постановка по предмету в руке (заявка с ячейкой панели), снятие одного предмета, снос возвращает предмет; сохранение массы.
2. Сеть: заявка постановки несёт ячейку; следующий номер протокола; «золотые» байты.
3. Сохранение: следующая версия формата, если меняется; файл предыдущей версии читается (настоящий файл, собранный прежним кодом).
4. Клиент: призрак и постановка от предмета в руке; ленту молота убрать; подсказка «ЛКМ — поставить, ПКМ — повернуть (если есть)».
5. `BuildHand` и бот `build_room`: бот сначала делает стены/пол/дверь у верстака (или руками — по рецептам), потом ставит; тяжёлый `D08_3_1_BuildRoom_Udp` зелёный.
6. Значки предметов-построек (скриптом, стиль «тёмный контур, плоский цвет», правила заглушек) — у каждого нового предмета.
7. Тесты: каждая постройка ставится из предмета; без предмета — отказ; снос возвращает предмет; стопка уменьшается на 1; сохранение массы при отказе сервера (предмет не пропадает); бот.
