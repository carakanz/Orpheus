# E4-1 — главное меню: новый мир, продолжить, открыть для друзей, войти по адресу

**Ссылки:** модули `work/modules/ui.md`, `work/modules/net.md` (читать перед шагом); `docs/07_multiplayer_tech.md` (подключение клиента).

## Зачем
Шаг 4.1 плана (`work/PLAN.md`, этап 4 «вдвоём по сети»): С + А. Сейчас игрок стартует
сразу в мир (`GameBoot`); чтобы играть по сети и принимать этап 4, нужно меню.
Разблокирует: 4.2 (два бота 30 мин), 4.4 (приёмка вдвоём).

## Что делаем
1. Экран меню в клиенте (процедурный UI, как окна C-015/C-030, шейдер `Resources/UiShape.shader`):
   - «Новый мир» — сгенерировать мир (зерно по кнопке/вводом) и войти локально (нынешний путь);
   - «Продолжить» — загрузить последний автосейв (тот же путь, что автозагрузка мира);
   - «Открыть для друзей» — локальный сервер в процессе (тот же `ServerHost`, адрес для друзей —
     по слову Автора; в тестах/приёмке — 127.0.0.2; НИКОГДА `--public`);
   - «Войти по адресу» — ввод host:port, подключение `NetClient` к серверу.
2. Точка входа: сцена Boot показывает меню; вход в мир — по выбору. Экран смерти/отключение —
   возврат в меню (не перезапуск процесса).
3. Меню не меняет протокол и формат сохранения. Если для «войти по адресу» нужен хендшейк —
   не менять протокол: адрес — только клиентский параметр подключения.

## Решения
- 19.11: «Открыть для друзья» в меню = тот же путь, что `--single --open-for-friends` (сервер — дочерний процесс через LocalServer, UDP-дырокол; в `--server-thread` он запрещён ClientArgs:629). Причина: путь обкатан host-smoke; in-process ServerHost для меню не нужен.
- 19.11: «Продолжить» = запуск сервера в самой свежей папке `Worlds/world-*` с `world.base` (сервер сам грузит сейв); «Новый мир» = следующая свободная папка + случайное зерно, зерно видно на экране NewWorld.
- 19.11: «Войти по адресу» не трогает протокол: Args.Connect (host:port); история адресов — файл `connections.txt` в persistentDataPath (клиентский параметр, per карточка п.3).
- 19.11: возврат в меню — перезагрузка сцены (не процесса): статический флаг ReturnToMenu; сервер штатно сохраняет мир в OnDestroy→Net.Shutdown.
