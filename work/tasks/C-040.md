# C-040 — дверь без заказчика заменяет стену без возврата (хвост C-029)

## Зачем
Хвост C-029 (`work/next.md`, строка C-029): «дверь без заказчика заменяет стену без возврата».
При постановке двери поверх стены в режиме стройки, если ставить некому (нет заказчика/персонажа
в радиусе — путь через бота/правки такта), стена сносится, а оплаты/возврата двери нет —
масса мира не сходится. Ядро (`src/Orpheus.Core/Sim/Simulation.Build.cs`).

## Что делаем
1. Найти путь постановки двери (`ApplyBuild`/постановка двери поверх стены) и ветку «заказчика
   нет/не в радиусе» — воспроизвести тестом: стена есть → правка ставит дверь → стена удалена,
   предмет двери не списан (или списан без возврата стены — уточнить по коду).
2. Починить по правилу C-029 (проверка «заявитель жив и в радиусе» в такте, как `ApplyChestOp`):
   отказ с кодом, стена цела, масса не меняется.
3. Тест red→green в `tests/Orpheus.Tests` (файл Build*/Door*); сверить с ночными ботами
   (`night_camp`/`build_room` — не должны сломаться).

## Готово, если
Тесты по фильтру Build|Door зелёные; П принято. Тяжёлый `-All` — перед слиянием (карточка трогает ядро).

## Правила
Правила боя/протокола не менять; проверки не ослаблять.
