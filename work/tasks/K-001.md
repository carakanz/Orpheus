# K-001 — процедурная анимация персонажей и врагов (вариант В из `work/animation_plan.md`)

**Поток:** К (клиент Unity). **Ветка:** `task/K-001` (рабочая копия `.claude/worktrees/tk001`). **Веха:** 0 → прототип вехи 1. **Зависимости:** нет; общий клиент с 0-031 (`--server-thread`) — сливать по очереди.

**Решение Автора 08.11:** игра остаётся 2D на Unity (`BRIEF.md`); анимация — процедурная сейчас, проба «вырезная против 3D→спрайты» — потом (A-003). Стиль Б (`art/style/STYLE.md`).

**Цель:** живая картинка без новых ассетов: один спрайт персонажа/врага + движение кодом. Только отображение — ядро, сеть и предсказание не трогать (анимация считается из состояния, которое клиент уже знает: позиция, скорость, уворот, угрозы «замах начат», правки).

## Шаги

1. **Слой анимации** (`client/Assets/Scripts/Anim/…`): чистый класс без Unity-зависимостей, где возможно, — расчёт смещения, наклона, масштаба по состоянию и времени; MonoBehaviour только применяет к Transform/SpriteRenderer. Тесты класса — в `tests/` (как `RemoteInterpolation`), если вынесен в ядро клиента без Unity.
2. **Ходьба:** покачивание вверх-вниз и лёгкий наклон по направлению; частота от скорости; на месте — дыхание (едва заметное масштабирование).
3. **Направление:** зеркало спрайта по горизонтальной составляющей движения/прицела.
4. **Уворот:** смаз (вытягивание по направлению рывка), наклон, «призрак» — 2–3 полупрозрачных следа; неуязвимость — мигание.
5. **Замах врага (телеграф 0,4 с):** манекен/враг — отклонение назад, затем рывок вперёд в момент удара; полоска или дуга сектора удара на земле (по `02` 3.1 — сектор); вспышка при попадании, отдача (сдвиг спрайта на 2–4 px назад) и красная вспышка у получившего урон.
6. **Копание:** персонаж «тычет» в сторону тайла (короткие толчки с частотой копания); частицы пыли/щепок у тайла; при откате — уже есть красный квадрат, оставить.
7. **Параметры** (амплитуды, частоты) — одним местом, легко подстроить.
8. Проверка: офлайн-`--smoke` и host-smoke код 0; **короткое видео или серия кадров** (`ScreenshotRun` — несколько кадров подряд, или запись кадров в PNG) — ходьба, уворот, замах манекена, копание — в `work/screens/K-001_*.png`; производительность: 60+ fps с 8 игроками и 40 врагами-болванками (замер).
