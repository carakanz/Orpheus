# C-022 — тесты не должны мигать экраном Автора (запуск OrpheusServer.exe)

Модули: `tools`, тесты. Ветка `task/C-022`, копия `.claude/worktrees/tc022`. Слово Автора 16.11: «сейчас мигает» (несколько раз за вечер, в том числе при оконной игре).

## Что найдено (Producer, 16.11 21:09)
Во время мигания быстрые тесты (`tools\ci.ps1`) запускали `tests\...\bin\Debug\net9.0\OrpheusServer.exe` по 1–2 раза в секунду, и каждый раз рядом рождался `conhost.exe 0x4`. Все места запуска уже стоят с `CreateNoWindow = true` (`HostProcessTests.cs`, `MetricsTests.cs`, `SaveKillTests.cs`, `src/Orpheus.Platform.Pc/PcServerLauncher.cs`) — значит, этого мало: создание консоли/процесса всё равно дёргает экран Автора (полноэкранная и оконная игра на основном мониторе).

## Что сделать
1. Запускать дочерние процессы тестов (сервер, лаунчер, `--launch`) **на скрытом рабочем столе** — как `tools\run_hidden.ps1` (CreateDesktop "OrpheusHidden", `STARTUPINFO.lpDesktop`), через общий помощник в тестах (P/Invoke `CreateProcessW` с перенаправлением stdout/stderr через пайпы, как сейчас `RedirectStandardOutput`), с флагами `CREATE_NO_WINDOW`. `PcServerLauncher` (его зовут и тесты, и клиент, который поднимает сервер сам) — добавить опцию «скрытый стол» (по умолчанию — для тестов; для игрока — тоже без окна, но на своём столе, если скрытый стол ломает что-то — решить и записать).
2. Проверить замером: короткий скрипт-наблюдатель (опрос `Win32_Process` раз в 200 мс или ETW, без прав администратора) показывает, что во время `tools\ci.ps1` новые `conhost.exe` больше не появляются **на рабочем столе Автора** (или не появляются вовсе) — описать метод и результат.
3. Если какой-то тест сам открывает консоль/окно (`UseShellExecute=true`, `cmd /c`, `powershell` без `-WindowStyle Hidden`) — найти и перевести на тот же помощник.
4. Всё, что меняется в логике тестов, — без ослабления проверок; быстрый CI зелёный (кроме `work/flaky.md`), сборка `-Smoke -HostSmoke` код 0.
5. Правило в `AGENTS.md`: дочерние процессы тестов и инструментов — только через помощник скрытого стола.
