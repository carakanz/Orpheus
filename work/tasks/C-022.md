# C-022 — тесты не должны мигать экраном Автора (запуск OrpheusServer.exe)

Модули: `tools`, тесты. Ветка `task/C-022`, копия `.claude/worktrees/tc022`. Слово Автора 16.11: «сейчас мигает» (несколько раз за вечер, в том числе при оконной игре).

## Что найдено (Producer, 16.11 21:09)
Во время мигания быстрые тесты (`tools\ci.ps1`) запускали `tests\...\bin\Debug\net9.0\OrpheusServer.exe` по 1–2 раза в секунду, и каждый раз рядом рождался `conhost.exe 0x4`. Все места запуска уже стоят с `CreateNoWindow = true` (`HostProcessTests.cs`, `MetricsTests.cs`, `SaveKillTests.cs`, `src/Orpheus.Platform.Pc/PcServerLauncher.cs`) — значит, этого мало: создание консоли/процесса всё равно дёргает экран Автора (полноэкранная и оконная игра на основном мониторе).

## Что сделать
1. Запускать дочерние процессы тестов (сервер, лаунчер, `--launch`) **на скрытом рабочем столе** — как `tools\run_hidden.ps1` (CreateDesktop "OrpheusHidden", `STARTUPINFO.lpDesktop`), через общий помощник в тестах (P/Invoke `CreateProcessW` с перенаправлением stdout/stderr через пайпы, как сейчас `RedirectStandardOutput`), с флагами `CREATE_NO_WINDOW`. `PcServerLauncher` (его зовут и тесты, и клиент, который поднимает сервер сам) — добавить опцию «скрытый стол» (по умолчанию — для тестов; для игрока — тоже без окна, но на своём столе, если скрытый стол ломает что-то — решить и записать).
2. Проверить замером: короткий скрипт-наблюдатель (опрос `Win32_Process` раз в 200 мс или ETW, без прав администратора) показывает, что во время `tools\ci.ps1` новые `conhost.exe` больше не появляются **на рабочем столе Автора** (или не появляются вовсе) — описать метод и результат.
3. Если какой-то тест сам открывает консоль/окно (`UseShellExecute=true`, `cmd /c`, `powershell` без `-WindowStyle Hidden`) — найти и перевести на тот же помощник.
4. Всё, что меняется в логике тестов, — без ослабления проверок; быстрый CI зелёный (кроме `work/flaky.md`), сборка `-Smoke -HostSmoke` код 0.
5. Правило в `AGENTS.md`: дочерние процессы тестов и инструментов — только через помощник скрытого стола.

## Готово, когда
- Замер «до/после» в карточке; Producer спрашивает Автора, мигает ли при прогоне `ci.ps1`.

## Решения
- Помощник — `src/Orpheus.Platform.Pc/HiddenProcess.cs` (в платформенном слое: P/Invoke и процессы — только там, docs/07 1.6). `CreateProcessW` на столе `WinSta0\OrpheusHidden` (то же имя, что у `run_hidden.ps1`), `CREATE_NO_WINDOW`, `STARTF_FORCEOFFFEEDBACK` (без курсора «запуск приложения»), `SW_HIDE`; stdin/stdout/stderr — трубы UTF-8; наследуются только они (`PROC_THREAD_ATTRIBUTE_HANDLE_LIST` + свой замок) — трубы параллельных запусков ребёнку не достаются; объект-задание (старт `CREATE_SUSPENDED` → задание → пуск): `Kill(entireProcessTree: true)` снимает потомков, закрытие задания их не трогает (сервер переживает бота, 2.3). Ручка стола держится до конца процесса-родителя (иначе потомок, позже загрузивший user32, не стартует — 0xC0000142).
- `PcServerLauncher(path, hiddenDesktop: false)` — новый ключ. Тесты и боты (`BotRun --launch`) — `true`. **Игра (`LocalServer`) — `false`, путь `Process` не изменён:** сервер игрока переживает игру (2.3), а скрытый стол живёт, пока его держит игра или кто-то на нём; сервер без окна, как раньше. Мигание у игрока не замечено (окно игры своё); если всплывёт — отдельная карточка.
- Цепочка тест → Orpheus.Bots → OrpheusServer (бот поднимает сервер тем же помощником) → conhost — вся на `OrpheusHidden` (замер). Потомок, запущенный обычным `Process.Start` без `lpDesktop`, по документации наследует стол родителя — замером не проверялось (таких мест в тестах не осталось).
- Наблюдатель `tools/watch_spawns.ps1` — без админа: Toolhelp32 раз в 200 мс (то же, что опрос `Win32_Process`, но без WMI) + чтение `DesktopInfo` и `WindowFlags` из PEB нового процесса (свой пользователь — `ReadProcessMemory` без админа). conhost приписывается родителю. Файл в UTF-8 с BOM (PowerShell 5.1).

## Отчёт исполнителя (16.11)
**Причина.** Тесты запускали `OrpheusServer.exe` через `Process.Start` с `CreateNoWindow` на столе Автора `WinSta0\Default`: на каждый запуск рядом рождался `conhost.exe` на том же столе (1–2 в секунду в `SaveKillTests`), плюс курсор обратной связи запуска. Всё это — на мониторе Автора поверх полноэкранной/оконной игры.

**Изменено.** `HiddenProcess` (новый), `PcServerLauncher` (ключ `hiddenDesktop`), `BotRun` (`--launch` → скрытый стол), тесты `HostProcessTests` (лаунчер + `Child`), `SaveKillTests.RunServer`, `MetricsTests.StartServer` → помощник; проверки тестов не менялись. Других мест с `UseShellExecute`/`cmd /c`/`powershell` в тестах нет. Правило в `AGENTS.md` (п. 0). Наблюдатель `tools/watch_spawns.ps1`.

**Замер** (`watch_spawns.ps1 -Filter tc022`, считаются только процессы этой копии; процессы te32 отсеяны по пути):

| Прогон | OrpheusServer/Bots | conhost на `WinSta0\Default` | conhost на `OrpheusHidden` |
| --- | --- | --- | --- |
| До: `D00_Save_Kill_StartPrune` + `D07_S2_13_9_Launcher` | 5 на Default | **6** (5 серверных + 1 testhost) | 0 |
| После: те же 2 теста | 5 на OrpheusHidden (флаги 0x181) | **1** (testhost) | 5 |
| После: HostProcessTests + SaveKillTests + HostTests без Big (19 тестов) | 59 на OrpheusHidden | **1** (testhost) | 58 |
| После: Big `D07_S1_9_7`, `D07_S2_3_…12s`, `D07_S1_9_4` (боты, метрики) | 4 сервера + 3 бота на OrpheusHidden | **1** (testhost) | 7 |
| **После, полный `tools\ci.ps1` (быстрый набор, 17.11, после слияния main): 1189/1189 зелёный, 156 с** | 56 серверов на OrpheusHidden | **1** (testhost) | 55 |

В том же окне замера параллельный прогон копии te32 (старый код) дал **56 conhost на `WinSta0\Default`** от своих `OrpheusServer.exe` — наглядное «до» на том же наборе. Узлы `dotnet build` (31 `dotnet.exe`) conhost на столе Автора не родили; прочие conhost на Default — от git/powershell/cmd агентов, не от тестов.

Остаток — один `conhost` у `testhost.exe` на запуск `dotnet test` (его рождает vstest) — не от кода тестов. 55 conhost при 56 серверах — один короткоживущий conhost опрос раз в 200 мс не застал; на Default ни одного серверного нет. Убрать можно, запуская `dotnet` в `ci.ps1` через скрытый стол; не сделано — прогоны остановлены координатором (слово «СТОП прогонов» 16.11), предложение — следующей карточкой.

**Тесты.** Все прогоны выше зелёные (2/2, 19/19, 3/3). Полный `tools\ci.ps1` (быстрый набор) после слияния `origin/main` — зелёный, 1189/1189, 156 с, код 0. Сборка клиента `-Smoke -HostSmoke` — **не запускалась** (координатор: утром, ночью на видеокарте локальная модель). Клиента касается только новый файл в `Orpheus.Platform.Pc` (игра его не вызывает, путь `Process` прежний) — сборку `-Smoke -HostSmoke` сделать по разрешению координатора до слияния.
