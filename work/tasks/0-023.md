## Шаги

1. **A*** на сетке тайлов: 8 соседей, без срезания углов у непроходимых, стоимость 1 за тайл, ×1,5 на замедляющих полах (в заглушке генератора их нет — тест на искусственной карте); эвристика — октильная по `Torus.Delta`. Проходимость — то же правило, что в такте (`Simulation.IsBlocked`); для летуна — режим «непроходимы только постройки и стены данжа» флагом (построек ещё нет — тест на искусственной карте).
2. **Окно 48 × 48** вокруг врага, не больше 1500 раскрытых узлов; неудача — «лучший частичный путь» к тайлу, ближайшему к цели по тору (9.2).
3. **Заворот:** координаты только через `Torus` (анализатор запрещает прямое вычитание); окно, пересекающее шов или угол, — обычное.
4. **Без выделений** в установившемся режиме (пул узлов, куча на массиве); **детерминизм** — при равных оценках порядок раскрытия фиксирован; хэш путей на 1000 поисков одинаков в двух прогонах.
5. **Бюджет такта** (`07` 2.4): очередь запросов, за такт не больше 40 поисков **и** не больше 3 мс, остальные ждут следующего такта; счётчики «выполнено / отложено / частичных». Время — монотонные часы; бюджет по времени не влияет на результат одного поиска (детерминизм пути сохраняется, меняется только такт, в который он выполнен).
6. **Цель в замкнутой области** (9.2): записей областей `05` ещё нет — для шипа заливка от цели в пределах окна; область замкнута, враг снаружи — A* не запускается, сразу «упёрся» у границы (вопрос ниже).
7. **Бенч** (отдельный тест `-All` или `tools/`): 1024², случайные стены (плотность и зерно записать), 1000 тактов × 40 поисков; цели в 5–40 тайлах, часть через шов, часть в замкнутых коробках, часть недостижима. Мерить: время поиска за такт (среднее, 99-й процентиль, наибольшее), раскрыто узлов, доля частичных, отложенных.
