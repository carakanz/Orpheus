# 1-020 — палитра строительства, призрак и автосоединение стен в Unity

**Поток:** К (клиент Unity). **Ветка:** `task/1-020` (рабочая копия `.claude/worktrees/t1020`). **Веха:** 1 «Прототип» (`08` 3.1, недели 16–17).

**Зависимости:** после слияния **1-011** (постройки вехи 1, запрос с id постройки, строки отказа) и **1-002**. **Параллельно можно:** 1-018 (общий `GameBoot.cs` — по очереди), 1-019, 1-021, 1-022, 1-024, все Я и М. **Ждут эту карточку:** 1-027.

**Цель:** с молотом в руках над миром сетка, внизу палитра; призрак постройки под курсором зелёный или красный с причиной; стены и заборы соединяются сами (прямая, угол, Т, крест), через шов тоже.

**Ссылки:** `docs/05_base_building.md` 1.2 «Сцена 1» (как выглядит), 1.3 «Режим строительства» (таблица: Q / E — категория, Z / C — постройка, ЛКМ — поставить, удержание — линия, Ctrl — по оси, ПКМ удержание 0,5 с — снос), «Правила постановки» (строки причин), «На торе и в перспективе» (стена 128 × 192 px, перекрывает тайл севернее, прозрачность 50 % над персонажем), 1.5 (предсказание и откат — красная вспышка с причиной), 1.7 п. 1 (что строит тестировщик); `art/style/STYLE.md`. Код: `client/Assets/Scripts/WorldView.cs`, `NetGame.Edits.cs`; заглушки — 1-024.

## Шаги

1. **Палитра вехи 1:** категории пол / стены / заборы / двери / свет; в категории — постройки 1-011; недоступные (не хватает ресурсов) — серые с подписью «нет ресурсов». Заглушки иконок — TEMP (`CLAUDE.md`).
2. **Призрак** под курсором: зелёный — можно (по общим правилам постановки ядра, вызов того же `EditRules` на клиенте), красный — нельзя, причина одной строкой («нет ресурсов», «занято существом», «враг ближе 2 тайлов», «обломки: N с», «сначала выкопать», «далеко»); линия при удержании — призраки по всей линии; Ctrl — только по оси.
3. **Снос** — ПКМ удержание 0,5 с, полоска прогресса над тайлом.
4. **Автосоединение** стен и заборов по 4 соседям (прямая, угол, Т, крест, торец) — спрайты из 1-024 или кодом; через шов; дверь в разрыве стены ориентируется по соседям.
5. **Перспектива:** стена выше тайла (1 × 1,5), перекрывающая персонажа стена — 50 % прозрачности.
