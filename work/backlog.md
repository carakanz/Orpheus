# Хвосты на будущие карточки

Пишет Продюсер из замечаний проверяющих; при нарезке карточек — перенести в нужную и вычеркнуть.

- [сохранения] Заголовок снимка генерации (зерно, версия генератора, форма) не защищён SHA-256 — проверено: перевёрнутый бит зерна грузится без ошибки (П по 0-005).
- [сохранения] Повторные чанки в снимке не отвергаются; нет предела размера при распаковке (П по 0-005).
- ~~[такт сервера] «Одна пачка правок на чанк за такт» держит вызывающий — закрепить в цикле такта; первая постройка в чанке выделяет 4 КБ (словарь записей) — пул или заранее (П по 0-005).~~ — закрыто 0-006
- [стройка] Блок, поставленный на персонажа, позволяет выйти сквозь стену толщиной 1 тайл — запрет ставить непроходимое на сущность (`05`: не ближе 2 тайлов к врагу) и проверка (П по 0-004).
- ~~[инструменты] `tools\ci.cmd` оставляет мусорный `log.txt` в корне (кодировка) (П по 0-004).~~ — закрыто 0-006
- [клиент] Сборка IL2CPP — нужен модуль Windows Build Support (IL2CPP), ставит Автор с правами администратора (0-002). Уточнение 06.11: `Data\il2cpp` есть, а в `PlaybackEngines\windowsstandalonesupport\Variations` только mono → ставить именно «Windows Build Support (IL2CPP)» через Unity Hub; после — `tools\build_client.ps1 -Backend IL2CPP`.
- [тесты] `D00_Sim_TickWithBotsEditsAndHash_AllocatesNothing` при полном параллельном прогоне падает на шуме GC (изолированно — 56 мс, проходит). В ночном `tools\ci.cmd -All -TimeLimitSec 0` гонять отдельным фильтром и записать базовую цифру аллокаций.
- [инструменты] `tools/Orpheus.View` без `--generation N` пишет «нет поколений», когда папка просто пуста (сохранений ни одного) — сообщение неточное.
- [мир] Генератор-заглушка: деревьев ~56/1000 тайлов лугов против 8/1000 в `01`; правило «объекты не вплотную» делает поле скал всегда проходимым — в настоящем генераторе для гор (`01` 3: 45 %, хребты) не применять (П по 0-007).
- [флаги мира] Хэш состояния пишет константу «флагов мира 0» — тест полноты хэша для флагов добавить в задаче с флагами (`07` 5.2) (П по 0-006).
