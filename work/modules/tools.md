# Модуль `tools` — CI, сборка, боты, снимки

## Отвечает за
Быстрый и полный прогон тестов, сборка клиента и сервера, боты, стенд снимков экрана, замеры, список хрупких тестов.

## Заморозка
Обвязка не растёт сама по себе: новая возможность — только если её просит шаг плана.

## Код
`tools/ci.ps1` (`-All -TimeLimitSec 0` — полный), `tools/build_client.ps1` (`-Backend Mono -Smoke -HostSmoke`), `tools/playable.ps1`, `tools/shots.ps1` + `shots.json` + `shots_sheet.py` (стенд снимков), `tools/gen_preview`, `src/Orpheus.Bots`, `tests/Orpheus.Tests`, `work/flaky.md`.

## Правила, которые нельзя нарушить
- Вывод тестов и сборок — в `build/logs/`, в ответ — только хвост.
- Unity — пакетный режим, один процесс на рабочую копию; Unity Hub и `Unity.Licensing.Client.exe` не убивать; код 198 = Hub не запущен.
- Тест, упавший не из `work/flaky.md`, — это красный CI, а не «хрупкий».
- Пороги проверок не ослаблять без записи в «Решения» карточки.
- **Запуски игры не перехватывают фокус (слово Автора 13.11).** Запуск с графикой — только через `tools\run_hidden.ps1 -Exe … -Arguments '…'` (невидимый рабочий стол; код выхода — код игры, 258 — не вышла за время). `tools\shots.ps1` делает это сам. Замер 13.11: `-batchmode` без этого забирал фокус окном `Orpheus` на каждом кадре; через `run_hidden` — ни разу. Сборочные smoke с `-batchmode -nographics` фокус не трогают.
- **Если запуск с окном неизбежен** (проверка руками, режимы без `-batchmode`) — всегда `-monitor 2` (неосновной монитор Автора, левый портретный 1440 × 2560), `-screen-fullscreen 0`, окно не шире 1400; в скриптах — параметр `-Monitor` со значением по умолчанию 2.
- Скрипты `.ps1` без BOM — только ASCII (PowerShell 5.1 ломает UTF-8 без BOM).
- **Скрипты из рабочей копии (`.claude\worktrees\…`) запускать так: `powershell -ExecutionPolicy Bypass -File .\tools\ci.ps1 …`.**
  Прямой вызов `.\tools\ci.ps1` там падает («running scripts is disabled on this system»), и в фоне это выглядит как
  «прогон идёт», а лог не появляется (15.11, C-005: фоновый CI умер молча, потеряно ~10 мин).
- Долгие прогоны (фильтр тестов ≥ 5 мин, `-All`, сборка Unity) — только в фоне; в том же ходе брать соседний шаг.
  13-минутный фильтр в основном ходе = «завис» (15.11, C-005).

## Как проверить
`tools\ci.ps1` — зелёный за ≤ 5 мин. `tools\shots.ps1 -Check` — все сцены сняты, повтор даёт те же файлы.

### C-025/C-026 (17.11) — HiddenCi в `tools\ci.ps1`
- `ci.ps1` гоняет `dotnet` на скрытом столе `WinSta0\OrpheusHidden` через `HiddenCi` (P/Invoke в Add-Type): conhost от testhost/MSBuild на столе Автора 1→0 (C-025).
- **Канализация (C-026): `STARTUPINFOEX` + `PROC_THREAD_ATTRIBUTE_HANDLE_LIST` (ровно inR/outW/errW) + job (`CREATE_SUSPENDED`+`Assign`+`Resume`).** В Add-Type PS 5.1 `SECURITY_ATTRIBUTES{bInheritHandle=true}` в `CreatePipe` не применяется (ручки ненаследуемые) → без списка ручек EOF по stdin к ребёнку не приходит никогда; с ним — 0,1 с. Job по таймауту снимает всё дерево (`TerminateJobObject`).
- Параметр `-StepTimeoutSec` (3600 с): висячий шаг снимается кодом 258 + пометка в stderr; грейс потоков — параллельный `Task.WaitAll(..., 60000)`.
- `-SelfTest` (код 0 = зелёный): таблицы `Join-CmdLine` (экранирование MSVC), гард stdin-читателя (powershell `ReadToEnd` по EOF; `cmd /c more` не годится — после EOF ждёт клавишу на `CONIN$`), гард таймаута (зависший ребёнок → 258).
- Быстрый CI: `tools\ci.ps1 -TimeLimitSec 0` (дефолт `TimeLimitSec=60` — легасюк, прогон ~145 с).

### C-033 (18.11) — шлюз чистоты процессов `-Hygiene`
- `tools\ci.ps1 -Hygiene`: на время шагов крутится `tools\watch_spawns.ps1` (наблюдатель spawn'ов, C-022) — сам запускается скрыто через новый `[HiddenCi]::RunAsync` (скрытый стол, без труб, вывод — TSV `build\logs\spawns.tsv`, остановка по `-StopFile`; `Register-EngineEvent PowerShell.Exiting` — стоп и при падении шага). НЕ `Start-Job`: job-воркеры сами плодят conhost на столе Автора.
- Вердикт в конце: «hygiene: новых N, своих M, conhost на WinSta0\Default: K»; K > 0 → exit 4 (порог не ослаблять). «Свои» — путь содержит имя копии, ИЛИ conhost с родителем из-под копии (как в watch_spawns).
- Гард детектора в `-SelfTest`: наблюдатель (без фильтра) + проба `powershell -WindowStyle Hidden` (живёт ~6 с — у мгновенно умирающих процессов desktop по PEB не читается) → пойма ≥ 1, иначе FAIL.
- Замер 18.11: `-Hygiene` на tc033 — 1331 тестов, новых 740, своих 134, conhost на столе Автора 0.
