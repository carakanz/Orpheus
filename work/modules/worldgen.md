# Модуль `worldgen` — генератор мира

## Отвечает за
Что лежит в мире при создании: рельеф, вода, обрывы-границы, биомы, лес, земля, валуны, залежи, место старта, места интереса. Свободный мир из зерна — ничего не рисуется руками.

## Не делает
Не рисует (это `worldview`). Не решает, что чем копается (`building`, `items`). Не меняет мир после создания.

## Код
`src/Orpheus.WorldGen/` — `GeneratorV1` (этапы: `MacroGenerator` → `HearthStage` → `TileStage` [биом тайла → `WaterStage` → `TrailStage` → `CliffStage` → `FloraStage`] → `ConnectStage`), `ReliefMap` (высота и уровни 0…3), `GridField`, `LatticeNoise`, `BiomeTable`, `TileRules`, `TileWorldStats` и `CliffShapeStats` (числа приёмки). Типы тайлов — `src/Orpheus.Core/World/FloorId.cs`, `ObjectId.cs`. Превью карты — `tools/gen_preview`.

## Правила, которые нельзя нарушить
- Только целые числа и свой шум: результат одинаков на всех машинах (тесты хэшей генератора).
- Мир — тор: шум и все обходы замкнуты по обеим осям.
- Суша связна от старта без копания; у старта (радиус 150) нет обрывов, воды и врагов.
- Обрыв: объект с временем копания 0 (не ломается), `Solid`. Гряда — полоса 2–4 тайла, без прямых отрезков и вложенных линий; проход 4–6 тайлов не реже чем через 80 шагов гряды.
- Новый вид тайла = новое значение в `FloorId`/`ObjectId` + строка в `worldview.md` (как рисуется) + версия сохранения, если меняется формат.

## Как проверить
`dotnet test tests/Orpheus.Tests --filter "FullyQualifiedName~ReliefTests|FullyQualifiedName~GenV1"` (30 зёрен 1024²: доли, связность, расстояния). Карты 1 : 1: `dotnet run -c Release --project tools/gen_preview -- --world --map 0xE50007,1,2` → `work/screens/E1-6b_map_<зерно>.png`; числа по зёрнам без картинок (в том числе форма обрывов) — `--map 1-30`.

## Состояние (14.11, E1-6b, генератор версии 6)
- Есть: озёра (низины рельефа), 1–2 реки с бродами, песчаный берег; обрывы — плавные извилистые гряды скал толщиной 2–4 тайла вокруг гор и плато, один уровень, с проходами (E1-6b); тропы; лес куртинами с полянами и редеющей опушкой; луг с сухой травой и пятнами земли; деревья, кусты, валуны кучками; горы — каменистая земля, кучки валунов, медь (плиты нет); пещеры — гряды 20 %. Связность без копания: проход в обрыве, брод из песка, просека.
- На 30 зёрнах: вода 7,9–8,5 %, обрывы 0,8–1,8 % тайлов (49–114 гряд по 12–77 шагов на мир), лес 41–46 % под деревьями, луг 1,3 %, достижимо от старта 98,7–99,9 %; 1024² строится за ~130 мс (Release).
- Виды деревьев в данных не хранятся: один `ObjectId.Tree`; вид (3–4) и вариант спрайта клиент берёт по хэшу координаты и биому. Сторона обрыва в данных не хранится: клиент рисует гряду по соседним тайлам-обрывам (лицо — к югу, бока — к свободным сторонам).
- Нет: пятен залежей (медь пока россыпью в горах), мест интереса, мелководья в данных (клиент рисует отмель по расстоянию до берега).
- Клиент без сервера строит тот же мир, что сервер (`WorldGenModule`, v1) — E1-1; заглушка — ключом `--gen stub`.

## Параметры генерации (числа предварительные)
| Что | Где | Значение |
|---|---|---|
| Высота | `ReliefMap` | (h макрокарты + своё поле, ячейки 128, 64, 32) / 2; узлы шага 4 |
| Уровни 1…3 | `ReliefMap.LevelQuantiles` | квантили высоты 33, 50, 67 % |
| Озёра | `WaterStage.LakePerMille` | 7,5 % тайлов; лужи < 40 тайлов убираются |
| Реки | `WaterStage` | 1–2 на мир ≥ 1024, ширина 3–7, брод 5 тайлов каждые 160 |
| Берег | `WaterStage.ShoreMax` | песок 1–3 тайла |
| Без воды и обрывов у старта | `WaterStage.NoWaterRadius` | 158 тайлов |
| Обрыв: поле | `CliffStage` | (рельеф + 2 × размытая маска гор и пещер) / 3, ячейки 2 × 2, искривление координат ±10 тайлов (шум 64, 32); возвышенность — верхние 26 % (`LevelPerMille`) |
| Обрыв: форма | `CliffStage` | закрытие и открытие кругом 4,5 и 5 ячеек; острова и дыры < 400 ячеек убираются; полоса 2,4–4,3 тайла от края внутрь, дрожание края ±1 тайл (шум 8, 4) |
| Обрыв: проходы | `CliffStage` | 5 шагов каждые 64; гряда > 80 режется посередине; у тропы — тропа + тайл с боков; гряда < 28 и обрубок < 12 убираются |
| Тропы | `TrailStage` | 2 поля (ячейки 256, 128), ширина ≈ 2,6 тайла |
| Лес | `FloraStage` | ядро 60 % тайлов, опушка 10 тайлов (от 45 %), поляны 12 % площади, куртины — шум 8, 4 |
| Луг | `FloraStage`, `TileRules` | сухая трава 15 %, земля 3 %; деревья кучками 2–6 |
| Горы / пещеры | `TileRules` | валуны 8 % (мелкий шум) / гряды 20 %; медь 12 и 10 на 1000 |
| Связность | `ConnectStage` | цена: объект 1, скала 2, вода 3, обрыв 5 (проход 5 × 5); остров < 6000 тайлов за бродом > 12 и карман < 16 тайлов дороже 2 — не присоединяются |
