# Модуль `worldgen` — генератор мира

## Отвечает за
Что лежит в мире при создании: рельеф, вода, обрывы-границы, биомы, лес, земля, валуны, залежи, место старта, места интереса. Свободный мир из зерна — ничего не рисуется руками.

## Не делает
Не рисует (это `worldview`). Не решает, что чем копается (`building`, `items`). Не меняет мир после создания.

## Код
`src/Orpheus.WorldGen/` — `GeneratorV1` (этапы: `MacroGenerator` → `HearthStage` → `TileStage` [биом тайла → `WaterStage` → `TrailStage` → `CliffStage` → `FloraStage`] → `ConnectStage`), `ReliefMap` (высота и уровни 0…3), `GridField`, `LatticeNoise`, `BiomeTable`, `TileRules`, `TileWorldStats` (числа приёмки). Типы тайлов — `src/Orpheus.Core/World/FloorId.cs`, `ObjectId.cs`. Превью карты — `tools/gen_preview`.

## Правила, которые нельзя нарушить
- Только целые числа и свой шум: результат одинаков на всех машинах (тесты хэшей генератора).
- Мир — тор: шум и все обходы замкнуты по обеим осям.
- Суша связна от старта без копания; у старта (радиус 150) нет обрывов, воды и врагов.
- Обрыв: объект с временем копания 0 (не ломается), `Solid`. Проходы между обрывами есть всегда.
- Новый вид тайла = новое значение в `FloorId`/`ObjectId` + строка в `worldview.md` (как рисуется) + версия сохранения, если меняется формат.

## Как проверить
`dotnet test tests/Orpheus.Tests --filter "FullyQualifiedName~ReliefTests|FullyQualifiedName~GenV1"` (30 зёрен 1024²: доли, связность, расстояния). Карты 1 : 1: `dotnet run -c Release --project tools/gen_preview -- --world --map 0xE50007,1,2` → `work/screens/E1-2_map_<зерно>.png`; числа по зёрнам без картинок — `--map 1-30`.

## Состояние (13.11, E1-2, генератор версии 5)
- Есть: озёра (низины рельефа), 1–2 реки с бродами, песчаный берег; обрывы-границы линиями по уровням рельефа с проходами; тропы; лес куртинами с полянами и редеющей опушкой; луг с сухой травой и пятнами земли; деревья, кусты, валуны кучками; горы — каменистая земля, кучки валунов, медь (плиты нет); пещеры — гряды 20 %. Связность без копания: проход в обрыве, брод из песка, просека.
- На 30 зёрнах: вода 7,9–8,5 %, обрывы 1,7–2,8 % тайлов, лес 41–46 % под деревьями, луг 1,3 %, достижимо от старта 98,7–99,9 %; 1024² строится за ~130 мс (Release).
- Виды деревьев в данных не хранятся: один `ObjectId.Tree`; вид (3–4) и вариант спрайта клиент берёт по хэшу координаты и биому. Сторона обрыва — тоже у клиента: по соседям и `ReliefMap.Create(W, зерно).LevelAt(x, y)` (обрыв «смотрит» в сторону меньшего уровня).
- Нет: пятен залежей (медь пока россыпью в горах), мест интереса, мелководья в данных (клиент рисует отмель по расстоянию до берега).
- Клиент без сервера строит тот же мир, что сервер (`WorldGenModule`, v1) — E1-1; заглушка — ключом `--gen stub`.

## Параметры генерации (числа предварительные)
| Что | Где | Значение |
|---|---|---|
| Высота | `ReliefMap` | (h макрокарты + своё поле, ячейки 128, 64, 32) / 2; узлы шага 4 |
| Уровни 1…3 | `ReliefMap.LevelQuantiles` | квантили высоты 33, 50, 67 % |
| Озёра | `WaterStage.LakePerMille` | 7,5 % тайлов; лужи < 40 тайлов убираются |
| Реки | `WaterStage` | 1–2 на мир ≥ 1024, ширина 3–7, брод 5 тайлов каждые 160 |
| Берег | `WaterStage.ShoreMax` | песок 1–3 тайла |
| Без воды и обрывов у старта | `WaterStage.NoWaterRadius` | 158 тайлов |
| Обрыв | `CliffStage` | ячейка 4 × 4, линия в 1 тайл; разрывы шумом 10 % ячеек; проход 4 тайла каждые 12 ячеек; линия < 8 ячеек убирается |
| Тропы | `TrailStage` | 2 поля (ячейки 256, 128), ширина ≈ 2,6 тайла |
| Лес | `FloraStage` | ядро 60 % тайлов, опушка 10 тайлов (от 45 %), поляны 12 % площади, куртины — шум 8, 4 |
| Луг | `FloraStage`, `TileRules` | сухая трава 15 %, земля 3 %; деревья кучками 2–6 |
| Горы / пещеры | `TileRules` | валуны 8 % (мелкий шум) / гряды 20 %; медь 12 и 10 на 1000 |
| Связность | `ConnectStage` | цена: объект 1, скала 2, вода 3, обрыв 5; остров < 6000 тайлов за бродом > 12 и карман < 16 тайлов дороже 2 — не присоединяются |
