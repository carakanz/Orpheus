# Модуль `save` — сохранения (заморожен)

## Отвечает за
Файлы мира и персонажей, версии формата, чтение старых версий, атомарная запись.

## Заморозка
Меняется только когда шаг другого модуля добавляет данные, которые надо хранить.

## Код
`src/Orpheus.Save/` (`WorldSave`, `SaveContainer`, `SaveSections`, `WorldFolder`), инструмент `tools/orpheus-save`.

## Правила, которые нельзя нарушить
- Запись только атомарная: временный файл → сброс на диск → переименование. У Автора нет ИБП; отложенная запись запрещена.
- Новые данные = новая версия формата; старый файл обязан читаться (тест на файл прошлой версии). Сейчас формат 6.

## Как проверить
`--filter "FullyQualifiedName~Save"`.

## Состояние (13.11)
Есть: мир, постройки, позиция и сумка персонажа, обрыв записи переживается.
