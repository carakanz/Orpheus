# Модуль `save` — сохранения (заморожен)

## Отвечает за
Файлы мира и персонажей, версии формата, чтение старых версий, атомарная запись.

## Заморозка
Меняется только когда шаг другого модуля добавляет данные, которые надо хранить.

## Код
`src/Orpheus.Save/` (`WorldSave`, `SaveContainer`, `SaveSections`, `WorldFolder`), инструмент `tools/orpheus-save`.

## Правила, которые нельзя нарушить
- Запись только атомарная: временный файл → сброс на диск → переименование. У Автора нет ИБП; отложенная запись запрещена.
- Новые данные = новая версия формата; старый файл обязан читаться (тест на файл прошлой версии). Сейчас формат 7.

## Как проверить
`--filter "FullyQualifiedName~Save"`.

## Состояние (13.11)
Есть: мир, постройки, позиция и сумка персонажа, обрыв записи переживается.

E2-1 (14.11), формат 7: сумка — ячейками (121 байт в полях `EntityField.Inv` / `CharacterField.Inv`), кучи на земле — записи `CreaturesField.Pile` в разделе СУЩЕСТВА, `WorldField.NextPileId`. Сумка-счётчики форматов 4–6 (23 байта) читается и раскладывается по ячейкам (`Inventory.ReadLegacyPayload`); тест на настоящем файле формата 6 — `GroundItemTests.E21_Save_Format6_RealFile_…` (`tests/Orpheus.Tests/Golden/format6_bag.save`). Атомарная запись не тронута.
