# Модуль `net` — сеть (заморожен)

## Отвечает за
Протокол, сервер (вход, ввод, снимки, чанки, события), клиентская сеть, предсказание своего персонажа, хост из игры.

## Заморозка
Новые возможности сети не делаются. Разрешено: (а) чинить сломанное; (б) добавлять в протокол и снимки данные новых механик по просьбе модуля-владельца шага. Улучшения «на будущее» — в `work/backlog.md`.

## Код
`src/Orpheus.Net/` (`Protocol`, `Session`, `Transport`, `Hosting`), `src/Orpheus.Server`, `Orpheus.ServerHost`; клиент — `client/Assets/Scripts/NetGame*.cs`, `LocalServer.cs`, `ThreadServer.cs`. Дизайн — `docs/07_multiplayer_tech.md`.

## Правила, которые нельзя нарушить
- Сервер слушает только 127.0.0.1; `--public` не запускать никогда; в тестах «для друзей» — 127.0.0.2.
- Каждое изменение формата — следующий номер протокола и обновление «золотых» байтов. Сейчас протокол 20.
- Файл `NetServer*.cs` — не больше 600 строк.
