# Модули Orpheus — карта

План — `work/PLAN.md`. У каждого модуля один файл здесь. Берёшь шаг — читаешь файл его модуля, а не `docs/` целиком.

| Файл | Модуль | Зависит от |
|---|---|---|
| `worldgen.md` | генератор мира | `sim` (типы тайлов) |
| `sim.md` | такт, сущности, движение | — |
| `combat.md` | бой, враги, путь | `sim`, `daylight` |
| `building.md` | копание, стройка, двери | `sim`, `items` |
| `items.md` | предметы, сумка, крафт | `sim` |
| `daylight.md` | сутки и свет | `sim` |
| `net.md` | сеть (заморожен) | все модули ядра |
| `save.md` | сохранения (заморожен) | все модули ядра |
| `worldview.md` | вид мира в клиенте | `net` (данные чанков), `art` |
| `actors.md` | вид персонажей и врагов | `net`, `art` |
| `ui.md` | управление и окна | `net`, `items`, `building` |
| `art.md` | картинки и их конвейер | — |
| `tools.md` | CI, сборка, боты, снимки | все |

## Правила

- **Граница.** Модуль правит только свой код. Нужна правка в чужом — отдельный пункт карточки, и в файле того модуля строка в «Состояние».
- **Направление зависимостей.** Ядро (`src/Orpheus.Core`, `WorldGen`) не знает про сеть, сохранения и Unity. Клиент не содержит правил игры: он показывает то, что решило ядро. Генератор — чистая функция от зерна и координат.
- **Файл модуля — не длиннее 80 строк.** Разделы: «Отвечает за», «Не делает», «Код», «Правила, которые нельзя нарушить», «Как проверить», «Состояние», «Дальше». Подробности дизайна — ссылкой на раздел `docs/`.
- **Обновление.** «Состояние» и «Дальше» правятся в том же коммите, что и код шага. Старое не копить: что сделано — одной строкой.
- **Своя проверка у каждого модуля:** команда, которая за минуты говорит «модуль цел» (фильтр тестов, бот или сцены снимков). Она записана в разделе «Как проверить».
