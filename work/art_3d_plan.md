# Пачка 3D (после пачки 2D) — заготовка

**Решение Автора 09.11:** на Маке помещается только одна сеть за раз → сначала большая пачка 2D
(`art/style/sets/m1.json`, Z-Image base, ставится вечером), потом ставим 3D-модель и гоняем большую
пачку 3D. Сети во время пачки не менять; задания SpaceLions не вытеснять.

**Стиль:** Б в 3D (`art/style/STYLE.md` п. 12: toon-шейдер, обводка `#310B1D` ≈ 2 px при 1080p,
палитра-тройки, камера 45–55° сверху как Diablo). Кадр 2D-пробы = референс модели: форма, цвет, свет
сверху-слева, тень вниз-вправо.

## Порядок прогона

1. Пачка 2D `m1` собрана и просмотрена (лист сверки) — промпты-победители идут референсами в 3D-задания.
2. Ставим 3D-сеть (какая — решает Автор: на Маке что стоит; объём памяти — одна сеть).
3. Пачка 3D по таблице выше, по 2–4 варианта на модель; промпт = описание из m1.json + «low poly
   stylized game prop, toon shading, dark plum-brown rim, plain background, single object centered,
   three-quarter top-down game camera».
4. Приём: silhouette-лист, как у 2D; в движок — по карточкам 1-020/1-023 (замена TEMP-спрайтов).

## Запуск (вечер 2D)

```
python tools/mac_art.py queue art/style/sets/m1.json   # ставит в конец очереди, чужие не трогает
python tools/mac_art.py status                         # идёт/ждут
python tools/mac_art.py collect                        # качать по готовности
```

Обработка — `tools/art_process.py` (cover ≥ 0,10 — хвост из backlog закрываем в 1-024).
