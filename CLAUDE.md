# Orpheus — 2D-песочница сверху в духе Terraria по легенде об Орфее

Стадия: **дизайн**. Кода пока нет. Источник правды — `docs/` (начинать с `docs/README.md`); слова Автора — `BRIEF.md`, они главнее документов. При расхождении документа и брифа — спросить пользователя.

## Структура
- `BRIEF.md` — слова Автора дословно, рабочие допущения, открытые вопросы, выбор движка.
- `QUESTIONS.md` — сводный список вопросов Автору с допущениями, по которым комната работает до ответа.
- `docs/` — дизайн-документы по темам (`00_vision.md` … `08_roadmap.md`), все на русском.
- `design_room/` — комната, где документы пишутся: устав `ROOM.md`, роли `roles/`, переписка по темам `threads/<тема>.md`, состояние `state.md`.

## Как ведётся работа
- Два голоса: **Дизайнер** пишет документы, **Критик** разбирает. Запускает их и моделирует Автора **Система** (основная сессия). Подробности — `design_room/ROOM.md`.
- Документы пишутся «для реализации»: что видит игрок, что нажимает, правила, числа в таблицах, сетевые правила, критерии приёмки, что откладываем. Числа — предварительные, помечаются как такие.
- Движок — **Unity 6** (решение Автора 30.10, цель — порт на PS5); ядро игры — своя библиотека C#, совместимая с IL2CPP. См. `BRIEF.md` и `docs/07_multiplayer_tech.md`.
- Ссылки на файлы в ответах — полными путями (`C:\Users\carak\source\Orpheus\...`).
- **Коммиты (слово Автора 30.10):** код игры агенты коммитят, пушат в `origin` и сливают в `main` после проверки сами, без участия Автора — по правилам `docs/08_roadmap.md`, раздел 7.3 (ветка `task/<веха>-<NNN>`, WIP-коммит не реже раза в 30 мин и сразу пуш). `docs/` меняется только через комнату. Статус Автору — коротко после каждой задачи и раз в неделю сводка.
- **Временные ассеты (слово Автора 30.10):** пока нет ноутбука для генерации 2D, в игре — заглушки. Каждая заглушка помечена трижды: лежит в `Assets/Art/_TEMP/`, имя файла начинается с `TEMP_`, строка в `art/manifest.csv` со статусом `placeholder`; на самой картинке — пурпурный уголок (#FF00FF, 8 px). Заменять — тем же именем без `TEMP_` и статусом `final`; проверка `tools/check_temp_assets` перечисляет оставшиеся заглушки.
